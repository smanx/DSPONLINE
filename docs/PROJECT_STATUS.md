# DSP极简网络项目现状

> 基线日期：2026-07-22
> 产品阶段：首个公网版本已上线，当前更准确的定位是“公开测试版”。
> 事实来源：当前工作区代码、自动化测试、部署配置和线上只读检查。

## 1. 一句话结论

项目已经从单页挂机原型发展为一套可持续游玩的 2D 无限画布工厂游戏，具备本地存档、云账号与云存档、排行榜、PWA、Electron 桌面壳和双节点部署。现在最重要的工作不再是继续堆玩法，而是建立可复现发布、生产数据保护、安全加固、性能优化和原创化边界。

## 3. 已实现范围

### 核心玩法

- 不使用机甲角色，鼠标或触摸指针承担采矿、拿取、拖放、建造和跨星球托运。
- 以 React Flow 为无限画布，支持节点移动、框选、批量操作、蓝图、线路编辑、小地图和画布书签。
- 采矿、熔炼、制造、化工、科研、电力、行星物流、星际物流、戴森云、戴森球和银河终局形成完整流程。
- 六色矩阵、科研队列、五条无限科研、四类银河出口项目和八章战役任务已经落地。
- 生产库存对玩家使用整数结算，设备内部保留不可见的周期进度。
- 内容目录当前包含 78 个物品、78 条配方、32 类建筑、61 项科技、13 项成就和 32 个战役任务。

### 操作与分析

- 线路采用直接传送带连接，支持多输入、多槽物流站、自动物品/配方匹配、连接预览、吞吐预测和成功/失败反馈。
- 生产统计、网络诊断、跨星球物流诊断、工业规划、效率曲线、挂机压力测试和自动性能报告均有界面入口。
- 配方图鉴支持搜索、正反查、聚焦配方以及完整链和两层链展示。
- 施工托盘支持两行精简模式、批量扩建和 Ctrl 固定 `+1` 连续扩建；检查器可快速增加单台设备。
- 基础制造搜索工具固定置顶，建筑制造与物品手工分别保留最近 3 条搜索；建筑制造和物品手工中的可手搓缺料都能直达对应配方；自动整理支持独立的一步位置撤销。
- 闲置物流运输机和运输船使用全局随身载具库存，显示在底部施工托盘，可随玩家跨星球并从任意兼容物流站装卸；旧行星托盘中的闲置载具会无损迁移。
- 2026.07.21 版本公告首次进入时展示一次，并可从主菜单设置或游戏内设置重复查看；已读状态与游戏存档相互独立。
- 桌面和手机横竖屏均有专用布局、抽屉和触摸交互。
- 内容包支持校验、依赖、启停、运行时注册和存档使用保护；蓝图支持 JSON 导入导出。

### 存档与在线服务

- `GameState` 当前为 v24，存档封装格式为 v2，能够迁移 v1-v24 状态。
- 本地主存档有校验和、上一份有效备份、最近 5 个快照和 3 个手动槽位。
- 离线模拟默认最多 7 天，可由终局研究逐级提高到 30 天。
- 云服务提供注册、登录、30 天会话、修订式云存档、最近 20 个云历史版本、排行榜、反馈与客户端错误上报。
- 玩家进入工厂后发送匿名心跳；服务端只保存本机匿名 ID 的 SHA-256 哈希，并按节点统计累计、今日和最近 120 秒在线玩家。运营中心每 30 秒刷新这些聚合数据。
- 云存档使用乐观锁版本号处理冲突；排行榜要求先上传云存档并由服务端重新计算和约束指标。
- 服务端生产存储为 SQLite，每 6 小时备份一次，部署配置保留最多 30 份。

### 发布与运行

- Vite 生产构建拆分 React、React Flow、游戏核心和按需工作区。
- Electron 启用上下文隔离、sandbox、外链拦截和可选自动更新。
- GitHub Actions 可以按 stable、beta、nightly 构建桌面产物。
- Nginx 提供静态资源长期缓存、SPA 回退、安全响应头、TLS 和 `/api` 反向代理。
- systemd 配置包含云服务自动重启和每两分钟健康检查。

## 4. 版本基线

项目中同时存在三种版本概念，后续发布必须分别管理：

| 概念 | 当前值 | 用途 |
| --- | --- | --- |
| npm 应用版本 | `0.1.0` | Web/Desktop 发布版本与安装包版本 |
| 游戏状态版本 | `24` | `GameState` 结构迁移 |
| 存档封装版本 | `2` | 校验和、元数据和导入导出格式 |
| 云服务 schema | `3` | 云端持久化数据结构与匿名玩家统计 |
| 内容包格式 | `1` | 外部内容包交换协议 |
| 蓝图交换格式 | `1` | 蓝图 JSON 协议 |

不要把“v24 存档状态”当作“产品第 24 个发布版本”。下一个正式发布应先确定 SemVer，再生成可追溯构建 ID 和 Git 标签。

最近一次双节点 Web 与云服务发布为 `20260721T163957Z-bac953b6be93-dirty`，源 Git SHA 为 `bac953b6be93`；前端归档 SHA-256 为 `066699c6fb8cc0b20f387c341a9ae4b98df6b024f7e6ec5a088f99922a406488`，后端归档 SHA-256 为 `75f81a59a309a23ebde9ca810db9fbb57d04120dde533526e850dd3aa9c65f46`。香港与上海均已切换到同名的新前端和后端目录，云服务升级为 schema v3；切换前分别通过 SQLite Backup API 创建并验证了 `manual-20260721T163957Z-bac953b6be93-dirty.sqlite`。香港旧前端/后端为 `20260721T145356Z-bac953b6be93-dirty` / `20260721T101235Z`，上海旧前端/后端为 `20260721T145356Z-bac953b6be93-dirty` / `20260721T083538Z`，均继续保留用于独立代码回滚。`dirty` 明确表示产物来自当前未提交工作区快照，后续仍应先整理可复现提交再进行正式版本标记。

首个公网源码快照现已冻结为 Git 提交 `9acd4460868a4328a1b5e8bb3afbe736c7857e09` 并标记 `v0.1.0`。该标签用于追溯原始线上源码；标签后的构建改用“产品版本 + Git SHA + 可选 dirty 标识”的确定性构建 ID。完整发布证据见 [releases/0.1.0.md](./releases/0.1.0.md)。

## 6. 已知风险与技术债

### P0：发布与数据安全

- 当前工作树包含大量尚未提交的正式版本代码，线上版本难以从一个 Git 提交精确重建。
- `/api/metrics` 目前可匿名读取运行统计，应改为内部监控或受保护端点。
- 云服务是单进程、单 SQLite 文件架构，已有本机备份但尚未记录异地备份和定期恢复演练。
- 账号系统还没有邮箱验证、忘记密码、密码重置、管理后台和异常登录处置。
- 排行榜校验属于“云存档关联 + 指标约束”，不是服务端权威模拟，不能抵御有针对性的作弊。
- 上海入口是 HTTP，代码已禁止云登录；不能为了兼容旧地址而放开明文凭据传输。

### P1：性能与运维

- 线上 Nginx 当前未对 JS/CSS 返回 `Content-Encoding`。抽样主 JS 为约 411 KB，主 CSS 为约 317 KB；启用 gzip 或 Brotli 可明显降低首次加载流量。
- `src/styles.css`、`src/game/engine.ts`、`tests/e2e/game-flow.spec.ts` 和 `src/App.tsx` 已经成为超大文件，修改冲突和回归成本较高。
- 自动化发布目前覆盖桌面构建，但 Web/服务端仍缺少从提交到发布、健康检查和自动回滚的一体化流水线。
- 监控数据已采集，但外部可用性告警、日志集中化、磁盘水位和证书到期告警尚未形成闭环。

### P1：产品与合规

- 当前物品、配方、科技和流程以《戴森球计划》高还原原型为目标。公开推广或商业化前，应做名称、美术、文案、数值和世界观的原创化审查，并取得专业法律意见。
- 当前是公开测试版，不应把“功能很多”误认为“生产运营成熟”。隐私政策、用户协议、数据删除流程和公开反馈机制仍需补齐。

### 明确不在当前范围

- 黑雾或战斗系统暂不开发。
- 原创玩法扩展应排在稳定性、数据保护和发布工程之后。

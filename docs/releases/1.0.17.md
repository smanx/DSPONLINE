# 1.0.17 发布记录

日期：2026-08-01

## 代码与存档边界

- 本地开发基线为 GameState v44，存档 envelope 保持 v2；云 schema v7 和 SQLite layout v2 不变。
- v43 空间站实验资产不会并入量子网络；带有效空间站资产的 v43 存档继续明确拒绝加载，干净旧存档保留兼容迁移路径。
- 量子网络库存、传统物流路线、在途货物、生产、科研、戴森进度和确定性状态哈希不因本批 UI 或运行时缓存优化而改变。

## 量子物流接入修复

- 接入过渡会扫描全局 `stationRoutes` 账本，因此供应塔的路线即使保存在需求塔上也会被正确纳入。
- 普通模拟完成或删除旧路线后，过渡桥的 `remainingCargo` 会同步归零；不再因为过期尾货元数据永久停在“接入中”。
- 接入仍只在五秒结算边界完成，旧路线和在途货物不会被提前删除或重复结算。

## 画布性能 P1-P5

- 建筑、蓝图、货物和连接预览移到独立 `CanvasInteractionOverlay`，指针移动不再让整棵 React Flow 工厂树重渲染。
- 连接端口命中使用空间索引；拖动期间冻结对齐索引与线路中间点，结束后一次性重建。
- 手机双指缩放只在跨 LOD 档位时更新 React 状态；实体或线路密集时均启用可视区域裁剪。
- 暂停时停止线路采样、画布定时刷新和非必要动画；恢复后编辑操作仍即时反映。

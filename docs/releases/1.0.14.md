# 1.0.14 星区资料与大型工厂物流

> 发布日期：2026-07-31
> GameState：v42（v41→v42 仅增加星区显示元数据）
> 存档 envelope：v2；云 schema：v7；SQLite layout：v2
> Android：`1.0.14 / 1000014`

## 本批内容

- 星球和恒星系支持自定义名称、备注、标签、搜索和恢复默认。元数据进入本地/云存档，但不改变内部 ID、线路、物流和统计引用。
- 无限采集科技速度统一作用于固体、原油、液体、硫酸和轨道采集器；固体矿脉消耗降低仍独立计算。
- 十万级蓝图部署先规划全部建筑、矿机锚点、线路和施工库存，再一次性扣料；不足、非法安全整数或部署失败保持原状态。
- 物流诊断显示供应端送货/需求端取货，只检查派出载具的一侧翘曲器；同恒星系运输不消耗翘曲器。
- 物流候选索引修复无匹配回退全扫描问题，并保留传送带在存档中的顺序和旧公平轮询排序。Worker 复用运行时索引，不把缓存写入存档。

## 数据兼容

旧 v1-v41 存档统一迁移到 v42。缺失元数据使用空映射，名称、备注和标签在客户端与服务端均有长度、数量和目录 ID 边界。实体、线路、库存、科研、物流载具、生产进度、活动和戴森数据不重建、不删除、不覆盖。

## 玩家变化

- 本地主档、上一版本备份、自动快照、手动快照和三个槽位迁入 IndexedDB；成功提示只在事务完成并读回校验后出现。旧 localStorage 副本验证迁移后才删除，主档仍保留一份有界急救镜像。
- 动态模块加载失败会自动重试并检查 `version.json`；发布切换会归档当前版和目标版 hashed assets，让旧页面继续完成懒加载。
- 普通来源与分流器统一按高、标准、低分配，同级线路采用确定性轮询；两阶段转运避免第三条线路被来源缓存或一秒模拟步长饿死，线路转运额度最高可设为 100,000,000。
- 声明式内容包升级到 v2，支持安全白名单内的物品、建筑、配方、科技、数值覆盖和 4～32 级传送带；存档记录精确包版本，缺包阻止载入，启用 Mod 的主档不进入官方排行榜。
- 修复移动注册中文输入法组合态和兄弟字段被清空、部分 transform/小数像素造成的文字模糊，并补齐亮色主页和新增英文无障碍文本。
- 宇宙联合空间站物资收集任务取消结束倒计时并长期开放。原三天只控制假全服曲线，曲线冻结后巨构放置、任务进入和四项本地贡献仍可继续。
- 主菜单第一屏常驻醒目的“中文 / English”切换。语言偏好只按设备保存，不写入 `GameState`、本地存档或云存档。

## 存档与确定性

v39→v40 只增加 `settings.beltBufferLimit`、精确 `contentPacks` 引用和长期活动迁移。既有实体、线路、缓存、在途货物、物流载具、科研、制造 WIP、戴森与活动贡献不重建、不裁剪。服务端合法客户端范围扩展到 v40；envelope、云 schema 和 SQLite layout 均未升级。

IndexedDB 迁移覆盖主档、备份、自动/手动快照和三槽的导入、保存、重载、配额失败与读回校验。账号注册和登录不会重置未登录玩家的本地工厂。线路回归覆盖同级公平、高/标准/低、堵塞回退、10 秒/30 秒步长、刷新重载和整数物资守恒。

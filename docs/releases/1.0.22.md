## 本次内容

- 大存档上传改为异步 Worker 流程，离线结算、校验、压缩和上传分阶段执行，页面可继续滚动、取消和返回。
- 同一次上传复用已验证的最终 payload，避免重复 `JSON.parse`、`JSON.stringify`、checksum 和完整状态复制。
- 没有离线时间时直接使用当前权威内存状态；有离线时间时只通过已有离线 Worker 结算一次，失败或取消会给出明确提示，不覆盖本地有效存档。
- 上传界面在准备阶段立即显示状态并支持 `AbortController` 取消；保留 409 冲突、格式、完整性、体积和网络错误分类，以及 gzip/非 gzip 兼容路径。
- P3 保存短路、P4 增量协议、P5 批量线路层和 P6 多 Worker 安全门槛继续保持原有默认关闭策略，不改变确定性模拟和存档结构。

# 1.0.18 发布记录

日期：2026-08-01

## 功能与兼容边界

- GameState 由 v44 守恒迁移到 v45；存档 envelope 仍为 v2，云 schema 仍为 v7，SQLite layout 仍为 v2。
- 量子上传和下载是两个独立的存档级全星区额度：`400/分钟 × 银河物流倍率² × 已接入量子塔总堆叠`。
- 轨道采集器可单独或全星图批量接入量子采集网络，只上传、不下载、不贡献额外额度；接入前继续使用传统物流，旧星际航线尾货完成后原子切换。
- 量子模式只替代星际运输；本地运输机、槽位本地模式、优先级、库存、线路和在途货物继续工作。
- 每种量子物品容量可在 1 万至 100 亿之间独立设置，默认 100 亿。调低容量保留已有超额库存，只阻止继续上传。
- 星图新增独立量子空间库存面板，显示紧凑值、科学计数法、精确值、最近 5 秒上传、下载和净变化；中文、英文、桌面、手机和 200% 字号均有回归覆盖。

## 发布结论

`1.0.36` 已完成香港、上海 Web/API、上海下载页、Android stable APK 和 Windows stable 测试包发布。两地 Web/API 当前均为 `web-1.0.36-e0ad49062fa3` / `api-1.0.36-e0ad49062fa3`，上海下载站为 `download-site-1.0.36-e0ad49062fa3`。直接代码与下载回滚均为完整 `1.0.35-080844f55852`；代码回滚不恢复数据库。

本版上线传送带休眠与批处理、生产/物流可重建索引、新线路默认并联数、可燃冰火电和高密度 Canvas 空间命中优化。GameState v46、存档 envelope v2、云 schema v7、SQLite layout v2 和排行榜协议均未变化。

用户明确豁免精确候选 `1.0.36-e0ad49062fa3` 的 Android 物理真机、低配 Windows 和覆盖升级门禁，并接受开发交接记录的性能残余风险。该豁免不等于测试通过，也不适用于后续版本：20,164,029 字节存档的 60 秒精确模拟仍约 12.19 秒，极端 10,410 线路画布浏览器堆仍约 407MB。

## 原子切换与观察

顺序为香港 Web/API → 上海 Web/API → 上海下载页。Web/API 使用固定 `/usr/local/sbin/dsp-idle-switch-release`，切换时暂停健康、节点和对应异地备份/恢复 timer；香港使用扩展健康窗口并等待自动 COS 快照回到 `ready`，成功后恢复全部 timer。上海下载页使用受保护状态文件、临时 symlink 和 `nginx -t` 原子切换。

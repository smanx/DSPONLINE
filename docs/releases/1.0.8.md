## 玩家变化

- 保存、导出和云上传前立即自检；服务端独立复核并拒绝内部校验异常的存档。
- 校验失败不再显示虚假的 0 分钟/0 实体/0 科技。结构完整的存档可以先备份原件，再连续确认两次执行救援。
- 物资配送枢纽三个输入端口可分别指定物资、恢复自动识别或清空。重置连接会保护性返还线路、施工件、缓存和在途物资。
- 亮色模式下建筑制造和物品手工制造的正常、选中、可制造、缺料及禁用文字保持清晰。
- 运营中心新增默认关闭的性能页，按需显示 FPS、主线程、Worker、积压、内存、存档、行星规模和模拟阶段耗时，并可导出匿名报告。

## 存档与确定性

v38→v39 只增加配送枢纽三端口状态和线路端口归属。迁移不重建实体、线路、物流、科研、制造、活动或戴森状态，也不改变任何已有库存。异常存档救援先迁移可解析状态，再以确切序列化对象生成新校验；只有复核通过才允许载入。

用户样本只读核验结果：原 envelope v2 / 状态 v38，记录校验 `27ca23f8`、重算 `4d328e3c`；结构未截断。救援前后均为 12,143.1581 秒、149 个实体、50 条线路和 30 项已完成科技，救援后为有效 v39。样本未上传、未覆盖或写回。

性能监控只在玩家主动开启后向 Worker 请求阶段计时。开启与关闭路径的状态哈希相同；样本只在当前页面保留最近 60 秒，不写入 GameState、本地存档或云存档。

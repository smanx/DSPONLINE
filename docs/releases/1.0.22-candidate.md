## 本候选包含

- P3 保存重复短路继续只在上次写入、读回校验和主键均有效时生效；状态变化、失败和主键缺失仍完整保存。
- P4 增量 Worker 增加传输大小安全门。增量包不小于完整状态时自动回退完整状态，并保留 revision 边界；实验开关默认关闭。
- P5 批量传送带绘制层继续受终局模式、线路数至少 600 和设备级开发开关共同保护；未满足条件仍使用原 SVG/React Flow 路径。
- P6 多 Worker 继续默认单权威 Worker，仅保留只读基准规划门槛，不把分区探针当作正式模拟收益。
- 传送带流量衰减因子移到单次模拟窗口计算，结果和状态哈希不变。
- 真实终局夹具基准只在内存副本中解暂停，不写回或上传玩家存档。

P4/P5/P6 默认关闭；增量协议仍需真实 Worker 在途响应、内容包更新和移动设备 GC 长测。默认完整状态回传的长期内存平台期尚未满足，完整 E2E 需要在可稳定运行隔离 API 的环境重新执行。候选不改变生产数据库、云存档、旧存档或玩家库存。

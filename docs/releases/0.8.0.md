## 本次范围

- 长时间离线模拟移入 Worker，提供可取消进度，只在完整成功后一次提交；1 小时、8 小时、9 小时、24 小时、7 天和 30 天均与同步路径等价。
- 增加生产建筑与仓储物流建筑两项存档级缓存安全上限，支持 1万、10万、100万和 1,000～100,000,000 自定义值；降限、减堆和在途到货不会删除物品。
- 新建传送带支持默认货物堆叠和线路形状；蓝图、既有线路与并行线保留自身参数。
- 建筑堆叠、施工制造与手工制造支持数量输入、最大值、材料预览和递归原子规划。
- 戴森显示统一为 kW，并拆分理论接收率、接收站实际利用率和戴森功率利用率。
- 完善喷涂机安装诊断与手机制造搜索；储物仓和储液罐共用响应式端口布局。
- 新增五步基础操作导览；新版手机离线收益使用安全区模态，物流塔支持一键补满载具。
- 自动整理把矿脉、油井、海洋采集点与安装空间作为确定性障碍。
- 复杂工厂降低完整状态和画布发布频率，并完成 Chrome 与 360 各 30 分钟内存趋势采样。

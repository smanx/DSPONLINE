## No-Go 修复与剩余风险

- 本地合成测试覆盖真实软链接入口、持久 pending journal、writer lock、旧 API readiness、启动备份宽限、恢复 hold、3.2 GiB sparse/ext4 无 reflink预检和单 writer 状态机。
- Windows 无法执行真实 UID/GID、Bash flock、systemd-analyze、systemd/Nginx 实例和 ext4 行为；这些是 Release Agent 的硬门禁，不能记为通过。
- Android 真机、1.0.38→1.0.41 覆盖升级、低配 Windows、正式签名/安装包、23～48 MiB 真实设备传输、一小时离线/纯挂机、多标签页/多设备断网恢复仍待 Release Agent。
- 本版没有实现分块上传，也没有重写统一结算核心；超过保证边界仍会明确拒绝，快速结算继续使用既有近似误差策略。

## 回滚

- 未部署：废弃 `1.0.41-32daa4f94380` 候选即可，生产数据和现有 stable 不变。
- 已灰度：只把 Web/API 代码和配置指针切回验证过的上一不可变版本；不恢复生产数据库，不删除云 revision，不修改排行榜历史。

- Android/Windows 诊断制品不得进入 stable；正式包失败时继续保留现行 stable feed。

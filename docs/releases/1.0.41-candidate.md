## No-Go 修复证据

- 软链接真实执行测试会实际启动 handoff proxy，并执行 active environment、release switch 和 evidence CLI。
- 状态机 20/20 覆盖正常、幂等、Nginx test/reload、preflight、锁、new start/readiness、systemd 先副作用后报错、停止失败、进程死亡重入、published/mixed state、恢复再次失败和 rollback-last。
- proxy 连续合成流量切换 0 个 502/504；恢复失败保持 hold，不产生双 writer 声明。
- 3.2 GiB sparse、ext4 无 reflink 合成备份在约 10 ms 内拒绝，无整库复制，源大小/mtime/WAL 不变；独立预置副本可原子采用。
- 服务器级测试证明启动宽限内不会立刻生成备份；旧 `/ready` 404 立即兼容，503/不可写不误判。
- Windows 无法执行真实 UID/GID、Bash flock、systemd-analyze 和 systemd/Nginx 实例演练；这些不是“通过”，而是 Release Agent 的硬门禁。

# 1.0.3 递归制造与生产定位

> 发布日期：2026-07-26<br>
> Web/PWA：`1.0.3`<br>
> 游戏状态：`GameState` v36<br>
> 存档 envelope：v2<br>
> 云服务：schema v7 / SQLite layout v2<br>
> 原生安装包：公共 Windows/Android 稳定通道继续提供 `1.0.2`

## 玩家可见变化

- 物流运输船可从制造入口一键递归加工材料，成品直接进入全局随身载具栏；建筑制造中心也能把运输机、运输船作为目标库存。
- 建筑制造中心和快速制造共用完整材料链规划。高级、稀有资源与精简配方优先，整链无法完成时自动回退基础配方；铁矿石会继续经过铁块、钢材到最终建筑。
- 生产资料库的物品详情新增“定位产线”。当前行星可高亮全部生产设备及完整上游网络，多目标可逐个切换；其他行星结果可以直接跳转。
- 轨道采集器按自供能设施处理；物流运输船全部在途时显示舰队容量瓶颈，不再与航线缺电提示交替。
- 时间扭曲检查器同时显示请求倍率、实际倍率、需求功率、获得功率和自动降档原因。4x、5x、6x 均通过 60 秒真实产量测试，活动时钟仍只按真实时间推进。
- 枯竭矿脉显示醒目提示和资源模式快捷入口；有限/无限切换需要确认，并保留矿机、线路和缓存。显式为零的有限储量保存重载后保持枯竭。
- 建筑检查器可拆卸喷涂模块，返还模块、缓存增产剂和剩余喷涂点折算物；建筑随后恢复基础生产倍率。
- 鸿蒙 App 的新版手机建造搜索保留中文输入法组合状态，只有玩家关闭面板时清空；横竖屏与状态刷新不会覆盖输入。
- 储物仓、储液罐端口和文字适配 80%～200% 字号；物资托盘删除弹窗使用独立滚动区和固定操作区；折叠物资侧栏后容器、边框与背景全部退出。

## 状态与兼容性

v35→v36 只扩展建筑制造中心的持久目标与任务类型，使其可保存随身物流载具制造任务，并保存递归配方选择/回退说明。迁移会保留建筑、线路、所有行星库存、物流载具与在途航线、科研、蓝图、递归制造 WIP、活动和戴森工程。有限资源的显式零储量不再被迁移器当作缺失值恢复。

服务端云存档验证允许 v36；云 schema、SQLite layout 和生产数据库结构均未升级。主槽、三个手动槽、修订历史、冲突保护和排行榜规则不变。

## 发布与回滚

Web/API 制品从可追溯 Git 提交生成并分别发布到香港、上海的全新目录。两地发布前后均通过 SQLite Backup API 创建一致性快照和 `quick_check`，再使用固定切换工具原子更新；上海继续使用本机 Web/API，不代理香港。确切 release ID、manifest、备份和公网验收结果在完成生产切换后补录于本节。

本轮不构建、不签名、不上传 Windows 或 Android 二进制，也不修改上海下载站稳定更新清单。代码回滚只切换 Web/API release symlink，绝不回滚、替换或初始化生产数据库。

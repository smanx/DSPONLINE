## 发布范围

- 增加设备级简体中文/English 切换、`?lang=en` 入口和英文目录懒加载。
- 覆盖物品、配方、建筑、科技、行星、恒星系、生态、战役、成就及主要桌面/手机工作区英文文案。
- 补齐开始菜单、账号、云存档、排行榜、全屏工作区、模态和两套手机界面的亮色主题。
- Windows 与 Android 同步升级到 `1.0.2`，继续使用现有应用数据目录、更新通道和 Android 发布证书。
- 增加中英文 README 与 1.0.2 首次更新公告。

## 存档与数据边界

本次不修改 `GameState`、存档 envelope、云 schema 或 SQLite layout。语言偏好保存在 `dsp-idle-network.locale.v1`，不进入本地游戏存档、三个手动槽、主云存档或确定性哈希。亮色主题只改变展示，不影响模拟、库存、线路、物流、科研、戴森工程或排行榜。

双节点发布必须分别使用 SQLite Backup API 创建并验证备份。发布只切换新的 Web/API 代码目录，不上传、替换、恢复或初始化任何生产数据库；原生安装包只发布到上海下载节点。

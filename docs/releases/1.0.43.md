## 发布结论

1.0.43 已作为香港 Web stable 发布。生产收口状态为 generation 13：current Web `web-1.0.43-fceca3eda51c`、previous Web `web-1.0.42-c24e6247d257`；current/previous API 均为 `api-1.0.42-c24e6247d257`，pending switch 不存在，代理保持 forward，活动 API PID `181123`、`NRestarts=0`。上海 Web/API、上海下载页、Android 与 Windows stable 均保持 1.0.42；没有数据库 schema/layout 迁移、恢复或生产数据写入。

本版修复超大 v46 存档在旧线路迁移中的 O(E×B) 重复扫描，将其降为保持历史顺序和退款语义的 O(E+B) 索引/分区；导入与云恢复的完整检查移入独立 Worker；立即保存和受控返回改为单次可验证持久化链，并修复增产剂缓存 1 亿上限在重载时被误截为 10 万的问题。GameState v46、envelope v2、cloud schema v7、SQLite layout v2 和 IndexedDB records 均不变。

发布结论不代表全部卡顿已经解决。正式 36.7 MB 附件旅程中，导入、初次进入、手动保存和返回主页的持久化链正确且有界，但受控 Continue→Pause 仍耗时 `20,887 ms`，Long Task 峰值为 `20,291 ms`；玩家也独立反馈主动运行接近不可玩。该运行态问题从 1.0.43 残余风险提升为 1.0.44 P0，不能用本次迁移/保存修复宣称主动模拟已流畅。

## 发布结论

1.0.42 已完成双节点 Web/API、上海下载页、Android 签名 APK 和 Windows 安装包发布。公网 Build ID、健康/可写接口、排行榜、PWA、下载完整哈希、Range、缓存和 1.0.37 回退入口均已核验。两地继续使用相互独立的 GameState v46、envelope v2、云 schema v7 和 SQLite layout v2；本次没有数据库迁移、生产存档改写或排行榜历史修改。

本版以香港最终 1.0.41 P0 热修 `2e43f564…` 为父级，因此保留云 revision 正文定向回收和微型黑洞显式运行字段。已经持久化为暂停的黑洞仍不会被无依据自动开启。

## 玩家可见变化

- 35 MiB 等大本地存档在同一 writer 的解析、校验或 IndexedDB 首次写入超过租约周期时会安全续租，不再把自己误判为其他标签页覆盖。
- “当前为空、候选有效”时明确推荐采用候选；恢复按钮显示处理中、成功、具体失败和重试，写入并逐字读回校验通过后才清理冲突副本。
- 增产剂缓存新增 100 万预设，自定义范围为 1～100,000,000 的十进制正整数；生产倍率、消耗和补充逻辑不变。
- 无限矿物的合格速通 main 可提交正式速通榜，并显示“无限矿物”标签；普通银河榜、普通/速通存档隔离和其他作弊/实验限制不变。
- 无有效纯挂机会话时，遗留“未提交时间扭曲预算”会从最后合法检查点恢复：真实离线墙钟时间进入普通离线结算，未提交高倍率预算不发放，也不与普通离线重复结算。
- 原 1.0.42 UI 全面复核继续上线：动态安全区、手机原子导航、模态 inert/焦点恢复、80%～200% 字号和窄屏适配、中文输入法组合态与非敏感草稿保护、教程内容 revision 分离。

## 残余风险

- Windows setup 仍为 `NotSigned`，会显示未知发布者；不得写成已通过 Authenticode/SmartScreen。
- Android 只有官方证书模拟器覆盖升级证据，没有实体真机；iOS PWA standalone、低配 Windows、实体中文输入法和屏幕阅读器仍需后续真实设备抽检。
- 香港大库冷启动约三分钟；已有 300 秒发布 readiness 窗口，但不应以继续增大超时替代启动性能优化。
- 1.0.41 已持久化暂停的微型黑洞无法可靠区分玩家主动暂停与历史异常，1.0.42 仍不自动开启。
- 旧客户端保存超过其旧上限的增产剂设置时可能降级该偏好；多设备玩家应同步升级到 1.0.42。

## 回滚

1. Web/PWA 必须原子切回完整不可变目录，不能只替换 HTML、单个 JS 或 Service Worker。
2. API 代码回滚必须继续接受 1 亿增产剂上限和速通 `resourceMode`；不得直接回到不兼容验证器。
3. 代理热修可只把控制 symlink 原子切回 `1.0.42-c24e6247d257` 并替换代理进程；活动 API writer 和数据库无需重启/恢复。
4. 原生回滚只切 stable feed 或保留上一安装包，不卸载应用、不清玩家数据、不更换 Android 证书。
5. 所有回滚只切代码和静态制品，绝不恢复生产数据库，不删除云 revision、submission、排行榜历史、本地冲突副本或玩家存档。

## 画布 P0-P6 合并内容

- P0 性能监控默认关闭，只在玩家主动采样时记录 FPS、帧耗时、Worker 传输和画布归因。
- P1/P2 在普通模式下使用当前星球轻量投影、拓扑缓存和空间索引，所有数据都是由 `GameState` 派生的瞬时视图。
- P3-P6 只在设备本地开启“终局·极限模式”时启用节点 LOD、Canvas 批量线路、视口裁剪和低频小地图；任何 Canvas/小地图故障会回退完整 React Flow 路径。
- 多 Worker 正式执行路径已完成确定性与守恒验证，但真实终局档相对单 Worker 仍慢约 40%～73%；生产构建通过 `import.meta.env.DEV` 硬关闭该入口。
- 运行态拖动没有稳定达到 30 FPS，因此公告和下载页只描述可选画布路径，不宣称模拟运行全面提速。

## 已完成内容与证据

### 1. 建筑堆叠新增上限与历史存档保留（P0）

- `MAX_BUILDING_STACK_COUNT` 统一为 100,000,000；新增、矿机安装、堆叠调整、批量建造和蓝图部署等入口禁止继续增加到上限以上，并返回明确原因。
- 读取存档不再把历史 `machineCount`、`minerCount` 或历史蓝图中的安全整数静默截断到一亿。已有大于一亿且不超过 `Number.MAX_SAFE_INTEGER` 的值原样保留，可回收但不能继续增加。
- 0、负数、分数和不安全整数被拒绝，并给出备份/救援提示，避免精度损失或静默清空。
- 蓝图导入要求正安全整数且不超过统一新增上限，错误包含实际字段值和允许范围；边界值可完整导入、导出和再次解析。
- 云端 v46 校验接受历史安全超限的实体、蓝图和不可变蓝图版本，拒绝超过安全整数的危险值。

### 2. 独立物流管理页面（P1）

- 运营中心新增“物流管理”页，按恒星系、行星和物流塔分层展示，支持搜索、类型与异常筛选；只渲染展开的树节点。
- 支持行星物流站、星际物流站和轨道采集器，显示传统/量子状态，并编辑槽位、供需、本地/星际模式、优先级、库存上下限、舰队、翘曲器、自动补充和堆叠数量等现有能力。
- 远程编辑通过引擎域命令完成，不临时切换 `activePlanetId`。槽位改物品沿用危险操作确认边界。
- 筛选与展开状态只属于 UI，不写入 GameState。移动端控件达到 44 px，并验证 200% 字号横竖屏无横向溢出。

### 3. 连接传送带后精确选中线路（P1）

- `connectBeltWithResult()` 返回实际受影响的 `beltId`，新建线路和既有线路增加并联数均可精确定位。
- 匹配包含 source、target、itemId、targetPortIndex 和 tier；成功后清空建筑选择、设置单/多线路选择并打开 Inspector。
- 原 `connectBelt()` 保持兼容包装，不改变自动配方、端口规则或库存扣除。

### 4. 建筑托盘回收模式（P1）

- Construction Dock 增加回收入口，复用已有 selectionMode、单选、Shift 多选、框选、触摸选择和二次确认流程。
- 确认界面显示建筑数、相关传送带数和预计返还；提交仍调用 `removeEntities` 等域命令，未在组件中直接删除状态数组。
- 物流站、建筑制造中心等特殊建筑继续使用现有清理、任务取消和物资返还规则。

### 5. 物品悬浮卡快捷操作（P1）

- Item hover card 新增“定位”和“打开图鉴”，由 App 注入 `locateProductionLine` 与 `openRecipeFocus` 行为。
- 无生产来源时定位不可用并说明原因；Portal 支持从物品移动到卡片后继续交互。
- 移动端长按打开，两个操作区均至少 44 px。

### 6. 手机版蓝图导入（P1）

- 新版和经典手机 UI 均显示带文字的“导入蓝图”按钮，可触发现有 file input，并保留文件导入与粘贴 JSON 两种入口。
- 错误显示版本/格式等具体原因；成功显示建筑和传送带摘要并刷新编辑内容。
- 已验证 390x844 经典竖屏、844x390 新版横屏和 200% 字号。

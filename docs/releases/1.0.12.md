## 玩家变化

- 物资配送枢纽卡片改为紧凑稳定分区。80%～200% 字号、桌面、手机和平板下，端口、物资、库存和状态不会再把卡片异常撑大，三个真实连接点及命中范围保持不变。
- 线路“同步首条设置”按玩家逐条点选顺序固定模板。全选或框选没有明确顺序时必须显式指定并高亮模板，执行前显示摘要，完成后报告成功、跳过和失败数量。
- 同步线路会复制并联数量、货物堆叠、优先级、线路形态、监测和路由设置；累计运输、实时流量、进度和在途物资保持原样。
- 每台电磁轨道弹射器可选择当前恒星系的太阳帆轨道，桌面、新版手机、批量设置和蓝图共用同一领域命令。目标轨道失效、被删除或属于其他恒星系时，弹射器明确暂停且不丢太阳帆或发射进度。
- 亮色模式补齐行星物流站和星际物流站的槽位、物资、舰队诊断与设置项状态；默认、悬停、按下、选中、焦点、配置和禁用状态均有明确对比。

## 存档与兼容

GameState 从 v40 升至 v41，只新增弹射器目标太阳帆轨道。旧实体迁移时绑定所在恒星系当前活动轨道；旧蓝图部署时绑定目标恒星系活动轨道。太阳帆输入、发射进度、库存、线路、物流、科研和戴森工程不重建、不删除。

存档 envelope 继续为 v2，云 schema 继续为 v7，SQLite layout 继续为 v2。服务端接受合法 v41 存档并继续拒绝越界或校验失败载荷。代码回滚只切换发布目录，不恢复或替换生产数据库。

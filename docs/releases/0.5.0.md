## 本次范围

### 移动端、交互与性能

- 双指可从建筑、传送带或密集区域接管画布平移与缩放，第二指会取消第一指未提交的拖动、连线、采矿、放置和长按。
- 游戏区域拦截浏览器原生右键与系统长按菜单，同时保留输入框编辑、游戏内右键拖动和长按快捷菜单。
- 粗指针设备降低画布状态发布频率并默认关闭高耗能常驻效果；全屏工作区和页面后台期间冻结底层画布刷新。
- 科技树滚轮与触控板手势固定为横向移动，到达边界后不向外层页面泄漏纵向滚动。

### 建造、回收与画布管理

- 灰色快速建造锤改为单击上游缺料定位，锤子颜色和实际制造共用同一份完整材料链规划。
- 采矿机、原油萃取站和抽水站可按数量回收；矿脉、储量、缓存、生产进度和线路物资保留。
- 已堆叠普通建筑增加 `-1`，逐台返还施工库存；最后一台进入原完整拆除流程。
- 建筑制造中心使用真实约 2 倍节点尺寸和独立巨构状态效果，端口不依赖 CSS 缩放。
- 生产区域新增四边与四角共 8 个缩放手柄，桌面指针和手机触摸均可调整尺寸。

### 星际物流与资源

- 星际物流站可从所在行星物资托盘自动补充空间翘曲器，并设置目标库存；多个站点不会重复扣料。
- 新建到物资配送枢纽的输入线路默认低优先级，玩家手动设置和旧存档线路优先级保持不变。
- 澜渊 II、赤砂 I 和牧云 II 的原油资源按稳定 ID 无损补充；已有油井、矿储和自定义节点不覆盖。
- 殖民卡片固定显示物资来源、当前数量、需求数量及阻塞原因。

### P0 本地存档急救

- `productionHistory` 只保留在运行内存，不再持久化到主存档、备份、手动槽位或快照；刷新后统计曲线重新积累，不影响工厂进度。
- 自动快照从 5 份调整为 2 份，间隔调整为 5 分钟；手动快照和三个手动槽位不参与自动清理。
- 首次保存检测到旧大型自动快照时只保留最新一份，其余旧自动快照会被清理。
- 保存顺序改为轻量化、清理自动快照、写主存档、读回校验、尽力备份上一版本、最后创建自动快照。
- `QuotaExceededError` 只会从最旧自动快照开始清理并重试主存档一次，绝不自动删除手动数据。
- 只有写入与读回校验成功才显示“主存档已保存”；最终失败会持续显示红色告警和“立即导出当前进度”。
- 旧存档中的 2 秒和 10 秒自动保存设置迁移为 30 秒，当前选项为 30/60/120 秒。

## 已知限制

- 正式邮件发送器仍未配置完整的审核模板 ID 与最小权限 CAM 凭据，健康接口报告 `mailProvider: disabled`。新注册、邮箱绑定和找回密码继续显示“正在开发中”；现有账号登录、四槽云存档和已验证账号自动同步不受影响。
- 上海入口仍为 HTTP，只提供本地游玩与独立备用入口，主动禁用需要传输凭据的云账号功能。
- 上海文件系统本次验收使用率约 89%、剩余约 6.7 GiB，需要优先检查发布目录、日志和备份保留策略。
- 上海 Nginx 配置仍有同机其他站点遗留的重复 `server_name` 警告；当前 DSP 入口与本机 API 不受影响。
- 当前启用 gzip，尚未启用 Brotli；排行榜仍是云存档关联与服务端指标约束，不是服务端权威模拟。
- 当前未连接 Android 或 iPhone 真机，仍缺少 Android Chrome 与 iPhone Safari 各连续 30 分钟的耗电、温度、帧率和卡顿记录。Chrome 触摸仿真、正式域名横竖屏烟测与玩家本地验收不能代替该真机数据。

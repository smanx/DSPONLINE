## 本次范围

1. 电网满额供电时设备状态与实际生产效率统一为 100%，并补齐低电量和多设备分配回归。
2. 传送带连接默认锁定当前可用的最高等级，库存耗尽时逐级回退；并行线路优先沿用原等级，同时保留手动指定。
3. 科研支持暂停当前项目并保留投入进度，前置科技未完成时后续队列不会越级启动；科技树滚轮固定为横向浏览。
4. 工厂画布支持可命名、可配色的生产区域，仅作为视觉分区，不改变生产模拟。
5. 每颗行星可独立设置单种物资托盘上限，范围为 1,000 至 1,000,000；满仓不会吞掉来源物资。
6. 四向分流器优先模式修复为高（2）→标准（1）→低（0），同级轮流分配，高级线路堵塞后再回退。
7. 修复星图拦截其他工作区、小型储物仓端口重叠、200% 字体布局以及手机端释放后持续移动等问题。
8. 云服务增加旧账号邮箱绑定、邮箱验证和密码恢复协议；发送器未启用时相关入口明确显示“正在开发中”。
9. 云存档扩展为互不覆盖的主存档与手动槽位 1/2/3，支持修订历史、冲突选择和验证账号每 10 分钟自动同步。
10. 更新公告适配桌面、手机竖屏和横屏；关闭按钮与底部确认按钮固定可见，内容区域独立滚动。

两台节点的 `previous-release` 已有意设置为“旧 Web + 新 API”。因此以下命令只回退前端并继续保留 schema v6 后端：

```bash
sudo dsp-idle-switch-release --rollback-last
```

不得把 API 切回 schema v5 的 `0.3.0` 后端；代码回滚始终保留当前数据库，数据库恢复只能作为单独的灾难恢复决定执行。

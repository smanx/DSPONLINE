## 发布结论

`1.0.35` 已按用户明确授权作为香港 Web-only 测试版发布，与正式 `1.0.34` 并存。香港根站、香港 API、上海 Web/API、上海下载页、Android stable feed 和 Windows stable feed 均未切换；香港 `/var/www/dsp-idle/current` 与 `/opt/dsp-idle-cloud/current` 仍分别指向 `web-1.0.34-4a7d51241424` 和 `api-1.0.34-4a7d51241424`。

用户豁免了 1.0.35 的两台 Android 和一台低配 Windows 真机门禁，但本次豁免只用于这个隔离 Web 测试入口，不代表稳定版、Android 或 Windows 已满足发布门禁。未签名 Android APK/AAB 和 Windows 诊断目录包没有上传、没有进入下载页或稳定更新清单。

测试版复用正式 `1.0.34` API。GameState v46、存档 envelope v2、云 schema v7、SQLite layout v2 和正式排行榜均未改变；1.0.35 新增的服务端治理与管理员能力尚未部署到生产 API。

## 隔离规则

- 唯一入口为版本化路径 `/canary/1.0.35-48c74b7100dc/`，不建立会漂移的 `/canary/latest`。
- 测试路径返回 `Cache-Control: no-store, no-cache, must-revalidate`、`Vary: *` 和 `X-Robots-Tag: noindex, nofollow, noarchive`。
- `/sw.js?v=1.0.35%2B48c74b7100dc` 返回 404；正式 `/sw.js?v=1.0.34%2B4a7d51241424` 继续返回 200。
- 测试页面使用相对静态资源，并通过同源 `/api` 访问仍在运行的 1.0.34 API。
- 正式根页面、版本文件、Service Worker、下载跳转和稳定应用清单不由测试目录提供。

## 剩余风险与限制

- 两台不同档位 Android 和一台低配 Windows 的 30 天离线/纯挂机、后台、锁屏、弱网、温度和真实内存证据仍缺失；用户豁免仅适用于此 Web 测试入口。
- Canary 故意禁用自己的根 Service Worker，不能把该入口描述为可安装或离线的 1.0.35 PWA。
- 生产 API 仍是 1.0.34；1.0.35 的新服务端治理、账号处置和恢复能力没有上线。
- Android/Windows 1.0.35 诊断制品未签名或仅供诊断，禁止通过此链接或稳定下载页分发。
- 没有使用真实生产账号验证云读写；匿名 health 和浏览器 smoke 不等于真实账号端到端验收。

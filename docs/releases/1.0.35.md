`1.0.35` 已完成香港、上海 Web/API、上海下载页、Android stable APK 和 Windows stable 测试包正式发布。两地 Web/API 当前均为 `web-1.0.35-080844f55852` / `api-1.0.35-080844f55852`；上海下载站为 `download-site-1.0.35-080844f55852`。GameState v46、存档 envelope v2、云 schema v7 和 SQLite layout v2 均未变化。

## 原子切换与观察

发布顺序为香港 Web/API → 上海 Web/API → 上海下载页。Web/API 使用固定 `/usr/local/sbin/dsp-idle-switch-release`，切换前暂停健康、节点与异地备份 timer，使用扩展 health 窗口，成功后恢复 timer。上海下载页使用受保护状态文件和临时 symlink 原子切换。

香港新服务启动后按既有配置立即向 COS `auto` 前缀创建一次约 2.793 GB 快照，期间本机 health 曾因 I/O 超时；健康 timer 已暂停，服务没有崩溃或重启。快照收敛为 `ready` 后，本机连续健康通过并恢复三个 timer。发布收口时香港/上海 uptime 分别超过 24/20 分钟，服务 active、`NRestarts=0`，近 30 分钟 journal 错误命中为 0，各 DSP 专用访问日志最近 500 条 5xx 均为 0。根盘约为香港 76%、上海 83%。

旧候选 Canary 路由只比发布前 Nginx 备份多候选 worker 拒绝和版本化 alias。正式发布前已恢复原配置 SHA-256 `a28cd20218b883cf286322bda1980bd72b3d11a99a8774cafaaa718f87bda641`，另保留 pre-stable 安全副本；两次 `nginx -t` 和 reload 均通过。发布完成后安装的上一稳定版回退配置及其独立回滚副本见“发布后上一稳定版回退入口”，不能与已移除的候选 alias 混为一谈。

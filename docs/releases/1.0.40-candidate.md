## 主要开发结果

- 银河排行榜新增认证本人查询；公开榜仍是 Top 100，本人超过 100 名显示真实 `#N · Top 100 外`，服务器值与本地 60 秒最佳值分栏，窗口不足、零产出、隐藏、限制与复核状态不再混成“未上榜”。
- Web/Windows/Android/API 共用 30 MiB 保证正文契约、gzip、动态超时、requestId、取消与“提交结果未知后精确确认”。原始 payload、checksum、revision、历史与下载正文不改写，1.0.39 旧 JSON/Bearer 客户端继续兼容。
- 同一浏览器只有 writer lease 持有页可提交本地档；逐键 revision、fencing token 与 tombstone 阻止陈旧覆盖。真正分叉或刷新半写保存双方原始内容并要求玩家选择。
- 所有服务端 mutation 在 SQLite 事务成功后才发布到内存；失败不再暴露幽灵 revision。容量、20 条历史、正文内容寻址去重、流式 ZIP 账号归档、旧 JSON 归档导入与原子回滚已覆盖。
- Web 会话迁移到同源 HttpOnly cookie，旧 Bearer 保留兼容；Android 令牌迁移到系统安全存储。Android 系统备份只允许 `app_webview/Default/IndexedDB`，不备份令牌、cookie、偏好、缓存或私有导出。
- PWA 当前/上一稳定壳层原子更新，缓存命名空间不清理同源其他应用；新设备可直接发现 speedrun/main；关键弹窗统一焦点、inert、Escape 与危险确认语义。
- 上传只解析一次，1 MiB 以上正文转移给 Worker；服务端在线/排行榜建立索引和失效快照，高频运行数据增量持久化；首屏不静态加载 game-core、FactoryRuntime、flow-vendor、storage 或 legacyTranslations。
- 共享稀疏字段契约覆盖客户端投影与服务端结构验证，缺失默认值和显式非法值继续严格区分；防止再次出现 1.0.38 稀疏 belt 上传不兼容。

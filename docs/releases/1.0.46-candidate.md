# 1.0.46 发布前候选记录

> 状态：开发门禁完成，未发布；本记录不授权生产切换、正式签名或下载页更新。

## Scope

1.0.46 修复自动保存后模拟被暂停、主动暂停后模拟 Worker 无法恢复、纯挂机保存状态污染，以及手机连续拉线遮挡与候选状态机问题；同时把画布基础卡片、重叠处理和交互展开拆为三个独立本机偏好，并修复建筑消失、一行卡半截、空白视角无法恢复、过大的重叠数量标记，以及线路聚焦下选中/悬停卡片半透明、切换隐藏和无法平移画布。最终增量又统一了实时视口、节点虚拟化和小地图，收口放置/拉线后视角外节点不显示、拖动/框选失效和放置坐标错位。

## Implemented

- 普通构建默认使用 1.0.43-compatible verified-primary 保存协调器；durable WAL 只在显式开发变量下启用。
- 自动保存前正在运行的模拟在保存期间和完成后保持运行，玩家主动暂停仍保持暂停；新 Worker 安装会清除旧 disabled latch。
- 默认保护模式拒绝保存窗口内编辑但不暂停模拟；实验模式保留已接受编辑、失败进度和立即导出能力。
- 纯挂机只有在主存档验证、Worker 接管和恢复日志提交全部成功后才清理终态。
- next-mobile shell 只挂载一个无 backdrop 的可折叠底栏；6/10/50/100 条候选可滚动、定位、任意移除，重复或非法点击不阻断有效候选。
- 最终连接仍由 `connectBeltsAtomically()` 严格原子复核；失败保持零创建、零扣料并定位候选原因。
- 普通运行时异常与真实 chunk/module 加载故障分流，诊断不记录错误正文、存档、云数据或玩家隐私。
- 画布提供 `auto/full/medium/minimal`、`marker/representative/all`、`selected/hover/base` 三组独立设置，只写 localStorage。
- 数量标记缩为 `88×44` 点击区和约 `80×30` 可见胶囊；一行卡及 wrapper 固定 `96×32`，变换 viewport 禁用 paint containment。
- 普通节点、重叠 halo、交互展开与选中节点使用递增层级；展开卡通过屏幕 hit-test 回归确认不会被后渲染邻居遮挡。
- 线路/任务/生产链聚焦不会再淡化选中或悬停目标；dim 上下文节点不再制造 `nopan` 死区，点击建筑或画布可退出聚焦。所有 LOD 都有确定初始几何，展开过程不再出现 React Flow 隐藏帧。
- 一行生产卡显示“配方 · 产物”并保留特殊建筑名称回退；“完整 + 全部卡片”超过 480/1,000 个视口节点时启用明确标注的中等/一行密集保护，交互目标仍完整展开。
- fully-deferred 空白视角保留 Fit View 边界锚点；SVG MiniMap 与 CanvasMiniMap 均可恢复到建筑区。
- 普通平移、滚轮缩放和节点拖动触发的自动平移会在手势中发布带 overscan 的虚拟视口；小地图按 80 ms 上限实时重绘并在结束时补最终帧，拖动、框选和放置统一使用当前 transform。

# 1.0.46 本地候选记录

> 状态：开发候选，未发布；线上当前版本、回退和下载页均不在本记录范围内。

## Scope

1.0.46 只处理 durable 存档恢复、暂停后模拟 Worker 可用性、保存期间 revision/head 竞态和对应回归门禁；保留 1.0.45 空间站功能。

## Implemented

- Worker 重建统一清除旧 `simulationWorkerDisabledRef`。
- durable finalize/检查点失败后当前页读取 T0 recovery，在 recovery Worker 中精确回放 finalized/pending intent，将结果验证写入 T1，原子替换 head，再重建模拟 Worker。
- 若 T1 已完成精确读回但旧 head 替换失败，修复在保存锁释放后比较主存档身份，跳过旧 journal 并从新 T1 建立 head；默认保护模式不会用旧 UI 快照覆盖 T1。
- 失败时保持暂停和可导出边界；点击“继续模拟”会等待/触发同页恢复，不再强制刷新。
- 默认保存保护模式的 revision/head 一拍竞态改为安全采用最新已验证 revision；实验性编辑模式在 head 替换前再排空已接受编辑。
- 新增 finalize 故障注入 E2E，覆盖 pending intent 清理和继续模拟。

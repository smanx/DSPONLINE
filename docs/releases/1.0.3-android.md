# Android 1.0.3 云存档兼容发布记录

> 发布日期：2026-07-26
> 范围：Android 稳定 APK、上海下载站与本地香港 service 模板
> GameState：v36；存档 envelope v2；云 schema v7；SQLite layout v2

## 根因与修复

玩家截图中的“游戏状态版本不受支持或缺少实体列表”来自 Android 1.0.2 本地 `inspectSave()`：该版本最高识别 GameState v35，遇到 Web/1.0.3 产生的 v36 时会在网络请求前终止。服务端已经同时接受合法 v35 和 v36，因此不能通过服务端有损降级 v36 来掩盖客户端版本差异。

本次发布同签名 Android 1.0.3，内置 v36 加载与迁移、正式香港 API 和稳定更新清单。应用版本卡在 Android 1.0.3 首次显示时自动检查一次，仍保留手动重试。稳定清单最低支持代码为 `1000002`：1.0.2 的合法 v35 存档继续允许上传；本地或云端已经是 v36 时需覆盖升级后读取。

仓库香港 service 模板新增精确 origin `https://localhost`，服务端测试覆盖 GET、PUT 预检和未知 origin 拒绝。香港生产 unit 尚未同步该模板，因为当前开发机没有该实例的有效 SSH 授权；原生 Capacitor HTTP 主路径不依赖浏览器 CORS，但生产回退路径仍应在取得授权后部署并复验。

## 上海发布

上海下载站先从 `/var/www/dsp-idle-downloads/releases/1.0.2-df7bee45e60a` 原子切换到 `1.0.3-android-b8d43072`，最终以只修正文案的 `1.0.3-android-b8d43072-r2` 原子替换；APK 未重打、签名和哈希未改变。上一 1.0.3 目录与 1.0.2 目录均保留，Windows 1.0.2 安装程序、更新文件和哈希未改变，旧 Android 1.0.2 APK 继续可直接访问。

公网验证：下载页 `200`；稳定清单经香港 `302` 到上海后 `200` 且 no-cache；新 APK `200`、Range `206`、immutable；公网完整下载的大小和 SHA-256 与本地制品一致。发布后上海磁盘约剩 4.8 GiB，使用率 92%，后续原生发布需继续关注旧 release、日志和备份保留。

下载页桌面与 390×844 手机截图位于 `artifacts/qa/android-1.0.3-download-desktop.png` 和 `artifacts/qa/android-1.0.3-download-mobile.png`；两者均无横向溢出、版本错配或不可达按钮。

## 遗留事项

- 取得香港实例的有效 SSH 授权后，先通过 SQLite Backup API 创建并验证备份，再安装更新后的 service unit、daemon-reload、重启并验证 `Origin: https://localhost` 为 200、未知 origin 为 403。
- Windows 公开版本仍为 1.0.2，本次没有重打 Windows 安装包。
- 本次 APK 可由制品哈希和构建时 diff 标识追溯，但不是干净提交构建；下一次正式原生发布应先形成可重建提交。

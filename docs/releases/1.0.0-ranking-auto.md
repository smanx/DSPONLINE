## 发布范围

- 主云存档上传、十分钟自动同步和主槽历史恢复成功后，由服务端从存档计算并更新当前赛季排名。
- 服务启动时按用户 ID 确定性、幂等回填已有主云存档；手动槽位 `1`、`2`、`3` 不参与排名。
- 服务端忽略客户端提交的排行榜指标，只接受主云存档中的可信状态并保留服务端观察到的历史峰值。
- 账号级 `leaderboardVisible` 支持退出和重新加入。退出后主云存档仍可同步，但不会重新公开入榜；重新加入时立即从主存档恢复排名。
- 排行榜操作改为“立即刷新排名”，匿名访客可以读取真实服务端榜单；在线榜单不再混入模拟玩家。
- 本次发布不改变 GameState、存档 envelope、云 schema、SQLite layout、联合空间站活动配置或手动云存档语义。

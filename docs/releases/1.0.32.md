## 清理与剩余风险

最终验收后，只删除了两地 `/tmp` 中精确列出的上传 tar、清单和 Nginx 暂存配置；当前/回滚 release、数据库和备份均保留。香港还终止了一个已确认属于隔离预检、持有删除后 2.24 GB 文件的泄漏进程，生产端口、进程和健康均未受影响。清理后香港约 6.7 GiB 可用、根盘 83%；上海约 10.5 GiB 可用、根盘 82%。

- Windows 仍为 `NotSigned`，系统可能显示未知发布者或 SmartScreen 提示。
- 没有物理/模拟 Android 1.0.31→1.0.32 覆盖升级保档、Edge、Android WebView 或 Electron 长时真实夹具验收。
- 宏观纯挂机仍是受保护的仿射合同，不是任意复杂存档的 30 秒硬保证；复杂物流、流体、量子和有限矿脉场景可能回退精确或被资格门禁拒绝。
- 香港大库启动需要更长健康窗口；后续继续观察首轮健康延迟、RSS、WAL 和磁盘增长。
- 两节点都在 80% 磁盘告警区。不得删除当前版、回滚版或未证明已完成加密异地归档与哈希校验的有效数据库备份。
- 真实生产账号云写入没有执行，不能把未登录 401 和备份副本测试描述为真实账号端到端写入通过。

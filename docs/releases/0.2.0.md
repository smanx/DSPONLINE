## 本次范围

1. 建立隐私友好的访问、在线玩家、页面加载、LCP、API 延迟、错误、磁盘、TLS、备份与恢复指标，并用管理员 token 保护详细后台。
2. 完成可复现 Git/SemVer/Build ID/Manifest 基线、原子发布和固定路径一键回滚。
3. 账号系统升级到 schema v5：邮箱验证、密码找回与修改、设备会话、注销、数据导出以及本地存档绑定。
4. 云存档加入本地/云端摘要对比、显式冲突选择、修订历史与恢复；香港到上海的认证加密异地备份和隔离恢复形成闭环。
5. 完成手机端第三轮：双指缩放、触摸连线吸附、长按菜单、逐点多选、横竖屏状态保持和自动低性能模式。
6. 六颗行星加入确定性资源丰度、能源环境、运输距离和工业专长差异，并进入真实模拟。
7. 渐进教学延伸到红糖、石油链、黄糖、跨星球物流、戴森云和白糖，可定位停机设备或零流量线路。
8. 新增全星球生产管理、缺料/堵塞追踪、一键跳转、目标产量反推、批量配方和批量物流槽。
9. 主菜单按需加载工厂运行时，PWA 使用确定性缓存 ID；两节点启用 gzip，并完成全量测试与发布后浏览器烟测。

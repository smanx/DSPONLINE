## 发布范围

- 精确值提示改为唯一 Portal 层，统一鼠标、键盘与触摸生命周期。
- 深色/亮色语义主题覆盖画布、节点、线路、工作区、弹窗、表单和两套手机界面。
- 储物仓与储液罐共用响应式仓储节点，保持真实 React Flow handle 几何。
- v34→v35 增加建筑交互锁；锁定不影响模拟，但领域命令统一阻止移动、回收、堆叠、升级和配置修改。
- 检查器分区支持排序、折叠和恢复默认，偏好只保存在当前设备。
- 星际站翘曲器按塔内输入、未预留输出、所在行星托盘补仓；物流复检覆盖 50 艘、多塔公平、故障切换和航线归属。
- 行星物资托盘单种物品上限提高到 100,000,000，并同步迁移、任务奖励和服务端校验。
- 制造中心移除 128 次内部阶段截断，保留长时、高堆叠和高倍率的全部可用工时。
- 生产进度条、百分比和 ARIA 共用单一视觉进度，按真实模拟倍率平滑推进。
- 传送带使用近 5 模拟秒的累计运输窗口显示 `/s`，统一线路、检查器、统计与手机诊断。

## 存档与数据边界

v34→v35 只为旧实体写入 `interactionLocked=false`。迁移测试逐字段确认建筑、线路、库存、生产进度、载具、在途航线、科研、建筑制造任务、银河活动和戴森工程保持不变；重复加载幂等。存档 envelope、云 schema 和 SQLite layout 不升级。

物资托盘调低上限仍不裁剪已有库存，在途和保护性返还可以形成临时超额；自动写入在库存回落前暂停。服务端接受 v34 与合法 v35 主存档，拒绝非布尔锁值和越界、非整数托盘上限。

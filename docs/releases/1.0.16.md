## 新档周期性冻结修复

- 删除游戏画面中无条件每 5 秒检查所有本地槽位和快照的轮询。
- 只有打开“运营中心 → 存档”页面时，才会立即刷新并按设备类型继续轮询；移动端沿用 30 秒间隔。
- 保存、导入、恢复、删除和创建快照等主动操作仍在完成后刷新摘要，保证存档管理页面数据及时更新。
- 没有删除、覆盖或迁移任何本地存档；存档摘要策略不改变 GameState、云存档或排行榜数据。

## P0-B 存档保存路径

- 槽位和快照摘要按原始文本缓存；未变化的存档不会重复执行 JSON 解析、迁移和完整性校验。
- 自动保存只读取快照元数据来决定是否需要新的恢复点，并直接校验最新自动快照，不再为每次保存完整扫描历史快照。
- IndexedDB 主存档保存请求使用单任务合并，自动保存、页面隐藏和原生生命周期事件不会堆积并发写入；等待中的请求只保留最新状态。
- 旧快照首次需要完整摘要时交由 `saveSummary.worker` 校验；主线程只负责收集原始文本和应用摘要结果。Worker 不可用时保留同步回退路径。
- 长任务诊断按批次写入一次本地诊断记录，性能面板增加槽位数、快照数、总字节数及保存各阶段耗时。

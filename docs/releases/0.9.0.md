## 玩家可见更新

- 生产画面刷新增加自动调节、经典流畅 100 ms、高流畅 200 ms、均衡 500 ms、省电 1 秒、低配置 1.5 秒和极限省电 3 秒七档；固定档不会被自动策略覆盖。
- 移除实体与线路合计达到 180 后强制 3 秒刷新的规则。模拟运算、真实状态发布和视觉进度动画分离，档位切换不改变生产、物流、科研、戴森进度或离线结算。
- 绿色生产进度在真实快照之间平滑插值；库存数量仍只显示真实状态，当前选中建筑和检查器优先更新。
- 增产剂耗尽后回到基础倍率继续生产；三档增产剂缓存、旧存档迁移和界面状态保持一致。
- 物流塔匹配改为确定性索引和路线经济缓存，修正载具拥有方最低装载率，并保持优化前后状态哈希一致。
- 在轨太阳帆和壳面太阳帆统一为 88 kW/帆，结构点保持 960 kW；戴森球壳可复制到其他恒星系但不会复制施工进度。
- 四条长期科技扩展到 Lv.1000，连续体演算在 Lv.23 封顶；超大成本与投入使用 BigInt 精确结算和规范十进制字符串存档。
- 行星物资托盘增加筛选、全选、删除一半和删除全部；删除继续要求二次确认，数量统一支持万、亿、科学计数和精确值查看。
- 新增四输入银河物资出口、本地个人活动记录和服务器统一时间的模拟全服曲线。正式贡献确认、奖励和宇宙联合空间站本体仍未开放。

v32→v33 迁移新增增产剂缓存上限、精确无限科研进度、建筑制造中心递归任务在制状态和本地银河活动记录。迁移测试覆盖旧库存、实体、线路、物流载具、科研投入、戴森系统、银河出口与活动字段的幂等往返。

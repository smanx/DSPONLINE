## 玩家可见变化

- 已建传送带支持减号、直接输入和加号调整并联数量。增加会扣除同级传送带，减少会返还施工托盘；吞吐量同步变化，线路等级、形状、优先级、端口、货物堆叠和在途物资保持不变。
- 新版手机科技目录包含全部五项无限科技。完成宇宙矩阵后可正常发现和研究；空结果页可一键清除筛选，未解锁时显示真实前置条件。
- 建筑制造中心在完成“建筑仓储扩容 II”后，单种建筑或随身载具的自动补足目标最高可设为 100,000。调低目标只暂停继续制造，不删除已有超额施工库存。
- Windows 和 Android 客户端同步升级到 1.0.4。两者均保持既有应用标识，Android 保持长期签名证书。

## 存档兼容

本次不改变 GameState、存档 envelope、云 schema 或 SQLite layout，也不增加迁移段。旧存档中的建筑、线路、并联数量、在途物资、施工库存、物流载具、科研进度和戴森进度不需要重建。旧存档中已超过新建上限的传送带 bundle 不会被裁剪，可减少但不能继续增加。

Android 稳定清单的 `minimumSupportedVersionCode` 保持为 `1000002`。API 36.1 模拟器从正式 1.0.3 使用 `adb install -r` 升级到 1.0.4 后，`firstInstallTime` 不变，应用启动无致命异常。Windows NSIS 保持原 appId 和默认用户数据目录，安装包不包含删除浏览器存档或应用数据的步骤。

## 本次范围

1. 星图扩展为 8 个恒星系、22 颗行星和 16 种确定性生态模板，资源、稀有矿、海洋、潮汐锁定、能源、殖民成本与工业专长进入真实规则。
2. 恒星亮度影响太阳能、射线接收与独立戴森系统；跨恒星物流加入中转枢纽、优先级、二维距离和每船翘曲预算。
3. 紫糖阶段新增建筑制造中心，可按目标库存自动补足建筑；绿糖与白糖科技提高容量和速度。
4. 黄糖阶段新增三输入物资配送枢纽，线路送达物品可直接进入所在行星物资托盘。
5. 供电改为行星内全域电网，研究站支持未选项目时预接矩阵线，切换科研不拆线。
6. 后续母恒星系行星由星际物流科技解锁，运输机与运输船可作为随身载具跨星球携带。
7. 框选可包含传送带并一键升级；科技树滚动加入方向锁定。
8. 科技首次完成赠送对应建筑各 2 个；小锤子支持递归手工补料；新工厂获得铁、铜、石矿各 100。
9. 存档删除加入两次确认，账号入口支持忘记与重置密码，右上角工厂重置入口移除。
10. 修复移动公告关闭与载荷区域提示，加入 200% 字号适配和移动端触摸回归。

## 玩家可见变化

- “空间翘曲”科技增加原版高级配方：`1` 个引力矩阵制造 `8` 个空间翘曲器。原有引力透镜配方保留；递归制造优先完整可行的绿糖路线，不可完成时回退基础路线。
- 行星与星际物流塔支持输入运输机/运输船目标和一键填满；返还不得卸载执行中的载具。蓝图记录每塔目标，部署后从全局随身栏装载，库存不足时部分完成并显示缺口。
- 物资配送枢纽按所在行星托盘真实余量持续接收。“同步首条设置”和整网同步包含传送带并联数并守恒扣返施工库存。同恒星系航线不再预留或消耗翘曲器。
- 灰色快速建造锤按实时递归缺料链导航，原矿进入对应资源资料。生产面板显示行星冶炼专精等真实加成，玻璃统计与模拟口径一致。
- 人造恒星每台额定缓存 30 个反物质燃料棒。戴森球壳单位结构帆容量翻倍，标准单壳从 5,000 提高到 10,000。
- “矿脉极限利用”每级保持固体采矿速度 `+10%`，并新增固体矿脉消耗 `-10%`；Lv.10 起固体矿脉不再消耗储量。
- 建筑拖动结束立即保存世界坐标；加载、刷新、切换行星、字号和主题变化不再把渲染位置写回存档。

## 有限资源验算

从 Lv.0 开始完成矿脉极限利用 Lv.1～Lv.10 共需 `49,620` 个宇宙矩阵。按基础生产链和每一级研究完成后生效的消耗倍率，限制资源是煤矿：

| 项目 | 数量 |
| --- | ---: |
| 默认星区煤矿总储量 | 2,611,769 |
| 十级研究链实际消耗 | 571,824 |
| 完成后剩余 | 2,039,945 |
| 剩余 / 本次消耗 | 356.7% |

因此默认有限资源模式可以完成十级，并在最紧缺矿物上仍保留超过本次消耗 300% 的余量。该审计使用真实目录成本和基础配方递归展开，并由 `src/game/veinUtilization.test.ts` 固定。

## 存档兼容

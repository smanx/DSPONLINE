# 1.0.15 纯挂机与零基础教程

> 发布日期：2026-07-31
> GameState：v42（本版本不改变存档结构）
> 存档 envelope：v2；云 schema：v7；SQLite layout：v2
> Windows：`1.0.15` 未签名测试包；Android 正式签名包暂为 `1.0.14 / 1000014`

## 本批内容

- 时间扭曲装置统一为“开始纯挂机”模式。进入挂机覆盖层后，画布、建造、选择和非必要 UI 不可操作；生产、采集、物流、电力、科研、戴森和建筑制造继续通过 Worker 按实际倍率推进。
- 纯挂机状态沿用现有 `timeWarp.enabled` 存档字段，刷新或崩溃时从最后有效主存档恢复，不新增存档版本。停止挂机会等待运行中的安全分段，结算待处理预算并读回校验主存档；自动快照失败不会伪装为成功。
- 暂停成为模拟边界：暂停时计时器不再累计墙钟预算，Worker 不再提交新任务；正在执行且无法安全提交的分段会被丢弃，不会在恢复时变成暂停期间的补算。
- 设置 → 运行设置新增“完整自然语言教程”，包含桌面和手机示意、目录、搜索、术语表、版本号和独立阅读进度。教程覆盖从画布与采集到物流、戴森、巨构、性能和存档排障。

## 兼容性

旧 v1-v42 存档继续由现有迁移链读取。未运行纯挂机的存档行为不变；旧版仍保存的 `timeWarp.enabled` 会在新版本加载时恢复为可继续的纯挂机页面。教程进度仅存储在当前设备的独立 UI 偏好，不进入 GameState、导出文件或云存档。

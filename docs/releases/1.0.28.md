## 本次内容

- 统一亮色/深色语义主题，增加分类设置、离线版本历史、科技树滚轮和物品悬浮卡的鼠标、键盘与触摸交互。
- 普通建筑与物流塔使用守恒的堆叠目标；混合建筑/传送带选区支持原子批量增加，历史安全超限堆叠不会在读取时被裁剪。
- 物流槽位使用紧凑五行布局，同时保留 `routePolicy`、`warperBudget` 和 `minStock` 等历史字段及在途物资。
- 矩阵科研喷涂只开放加速模式；新增重整精炼并接入科技、配方图、统计与规划，递归规划不会把循环当作免费来源。
- 生产统计按状态和星球范围缓存并由 Worker 按需计算；时间扭曲增加分段预算、取消与积压保护。
- 排行榜新增服务端权威的白糖 `/min` 类别，只使用相邻有效主云修订计算，首次、回滚、短区间和内容包存档不参与。
- 本版不升级 GameState、存档 envelope、云 schema 或 SQLite layout；代码回滚不恢复数据库。

## 剩余风险

- Windows 安装程序仍为 `NotSigned`，Windows 可能显示未知发布者或 SmartScreen 提示。
- 本轮没有连接物理 Android/iPhone，也没有执行真机长期温度、耗电和帧率测试；签名连续性、递增 versionCode 和 Chromium 触摸场景已验证。
- 没有使用生产账号执行认证后的云存档写入 smoke，这是明确的生产数据保护边界。
- 真实 Chrome 鼠标滚轮在科技树中会同时产生横向和科技树自身的纵向位移，并记录 `Unable to preventDefault inside passive event listener invocation.`；窗口页面没有纵向穿透，主功能可用，但“统一为纯横向移动”没有完全满足。现有合成 `dispatchEvent` E2E 不会触发浏览器默认滚动，后续应由开发角色改为非 passive 原生监听并补充真实 `mouse.wheel` 回归。
- 香港根盘 84%、上海 80%，均已达到 80% 告警线。不得删除当前版、回滚版或有效备份，应继续按既有异地归档策略治理容量。
- 上海 `nginx -t` 仍报告其他站点既有的重复 `server_name` warning，但 DSP 配置语法、服务、健康与专用 access log 均正常；后续运维应单独整理旧 vhost，不与本次代码回滚绑定。

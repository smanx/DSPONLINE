## 八项实现状态

### 1. 建筑选中状态稳定与高亮（P1）

- `onSelectionChange` 会忽略 React Flow 在模拟状态重派生期间发出的瞬时空选择；画布空白点击、选择模式/删除模式仍是明确取消路径。
- 选中 ID 继续由 App 的权威 UI 状态驱动画布节点；刷新、性能模式和 Worker 状态发布不会清空选中集合。
- 选中节点增加持续边框、底色、发光轮廓和“已选中”标记，缩小 LOD 仍保留选中样式。
- 选中其他建筑、线路或空白画布仍按原有路径切换/清除。

### 2. 资源不足自动跳转开关（P2）

- 新增 `GameSettings.autoShortageNavigation`，默认 `false`，旧存档读取时缺失则使用关闭状态。
- 主菜单和运营中心设置均可切换；关闭时缺料只显示提示，主动点击灰色锤子、缺料文字或图标仍打开对应配方/图鉴。
- 快速制造失败只在开关开启时自动打开缺料配方，不改变材料扣除或制造事务。

### 3. 生产统计按星球筛选（P2）

- `calculateFactoryStatistics(state, planetScope)` 支持“全部星球”或单个星球，库存、生产/消耗、异常和电力消费者均按所属星球过滤。
- 统计下拉显示玩家星球名与所属星系；切换不重置搜索、排序和时间窗口。
- 运行中的生产历史增加可选的星球分桶字段；旧历史没有分桶时安全回退到当前筛选速率，不改变 GameState 版本。

### 4. 建筑上下游寻线模式（P2）

- `analyzeEntityLineTrace()` 对当前星球物理传送带做双向 BFS，覆盖上游、下游、分支、汇流和循环；访问集合保证循环不会无限递归。
- 结果按 `canvasTopology.revision + planetId` 缓存，拓扑未变化时不重复全量遍历；跨物流塔/量子网络只追踪到当前星球边界。
- 画布工具栏提供开关，运营中心提供“寻线模式默认开启”；偏好保存在 `dsp-idle-network.line-find-mode.v1`，不写入 GameState。
- 中心建筑使用醒目高亮，上游使用蓝色、下游使用橙色，无关节点/线路降低亮度；关闭模式立即恢复普通显示。

### 5. 自动保存 10 分钟与关闭（P1）

- `AutosaveIntervalSeconds` 扩展为 `0 | 30 | 60 | 120 | 600`；`600` 显示“10 分钟”，`0` 显示“关闭”。
- 周期计时器在 `0` 时不创建；进入后台、页面隐藏、退出和返回主菜单的紧急保存仍保留。
- 本地自动保存与云自动同步没有合并开关；手动保存、导出和手动上传不受关闭周期保存影响。

### 6. 终局极限模式节点标题（P2）

- `FactoryNodeLodView` 在有配方时优先显示配方名；无配方但有输出时显示主要产物；矩阵研究显示当前科技；机器未配置时显示“未设置配方”。
- 物流、仓储、电力、分流等无配方设施仍显示建筑名；建筑类型作为次级文字，完整名称通过 `title` 可查看。
- 只复用轻量节点快照字段，没有新增高频订阅或额外动画。

### 7. 设置页面窄屏/大字号布局（P1）

- 设置行使用 `minmax(0, 1fr)`，620px 以下、390px 以下和高分辨率场景自动切换单列/稳定开关列。
- 标题与说明不再逐字强制换行；按钮段可换行，开关有固定触控尺寸，不与说明重叠。
- 已沿用现有 80/100/125/150/200% 字号、手机横竖屏和移动壳层测试矩阵。

### 8. 左右侧栏独立收起/展开（P2）

- 物资侧栏和检查器分别增加边缘箭头按钮，并保留画布工具栏快捷入口；收起后对应宽度为 0，画布回收空间，不留下黑色占位。
- 展开/收起不清除选择、标签页、滚动位置或模拟状态；CSS 动画在极限/减少动画模式下可直接切换。
- 状态保存到 `dsp-idle-network.sidebar-preferences.v1` 本地 UI 偏好，不写入 GameState、云存档或排行榜。
- 边缘按钮使用与工具栏不同的无障碍名称，避免重复命中；桌面窄窗口与平板横屏保留稳定触控区域。

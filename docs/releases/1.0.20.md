# 1.0.20 发布记录

日期：2026-08-02

## 功能与兼容边界

- 量子供应塔在物资实际送达时优先直接写入量子共享库存；容量不足的部分精确回落到本地缓存或源端，保持整数、守恒和旧存档兼容。
- 传送带、本地物流运输机和供应塔本地溢出缓存共用同一即时入库路径；下载侧仍按原五秒边界聚合，不重复上传。
- 云存档服务兼容普通蓝图建筑遗留的 `quantumTarget: false`；客户端只为星际物流站保留该字段，普通建筑和蓝图保存时清理遗留字段。
- 服务端将格式无效、完整性校验失败、存档体积超限和请求体过大分别返回，不升级 GameState v46、存档 envelope v2、云 schema v7 或 SQLite layout v2。

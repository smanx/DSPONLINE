# 1.0.19 发布记录

日期：2026-08-01

## 功能与兼容边界

- GameState 由 v45 守恒迁移到 v46；存档 envelope 仍为 v2，云 schema 仍为 v7，SQLite layout 仍为 v2。
- 量子上传和下载继续是两个独立的存档级全星区额度，公式统一为 `5000/分钟 × 银河物流无限科技倍率² × 全部量子塔堆叠总数`。轨道采集器共享上传额度但不额外生成带宽。
- 内容包运行时注册表通过带 revision/fingerprint 的可序列化快照同步到实时、纯挂机和离线 Worker。注册表变化建立模拟边界，旧 Worker 响应不能覆盖新状态，`GameState.contentPacks` 仍只保存 `{ id, version }`。
- 蓝图建筑堆叠上限统一为 `100,000,000`，导入不会静默截断；新增对齐辅助线、量子网络目标状态、灰色待建、分次补料、载具后补和取消原子返还。
- 递归手搓和建筑制造保留必要 WIP；氢等额外副产物在托盘安全上限之外仍可被后续生产消耗，不会因隐藏缓存永久阻塞。
- 生产统计支持稳定目录顺序、生产/消耗排序、每秒/每分钟/每十分钟/每小时窗口和万、亿、兆、京及科学计数法。浏览器原生确认框统一替换为可恢复焦点的游戏内异步确认框。
- 旧存档、旧蓝图、库存、线路、物流槽、载具、在途物资和生产进度均按守恒迁移；不把完整内容定义写入 GameState。

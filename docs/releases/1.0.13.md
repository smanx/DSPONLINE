> 日期：2026-07-30
> 状态：香港与上海 Web/API、上海下载站和 Windows/Android 原生包均已发布
> GameState：v41

> 云 schema：v7
> SQLite layout：v2
> Android：`1.0.13 / 1000013`

## 玩家变化

- 大型工厂画布缓存稳定拓扑、端口占用、线路束和避让几何；未变化节点与线路不再随每次状态发布重复创建。
- 当前行星达到 300 个实体后按视口裁剪。普通与移动小工厂保持全部节点可达，直接定位、蓝图、拖动、连线和真实端口几何不变。
- 修复建筑缩小后持续灰色的问题。建筑低细节只由真实缩放决定，放大后恢复名称、库存、进度、状态和操作。
- 跨星系物流路径按行星对、策略、翘曲预算和路线环境复用，减少大型物流网络重复搜索。
- 排行榜不再把各项指标强制截断到一千万亿。数量显示扩展到“载”，功率显示扩展到 QW，更高值使用科学计数法并提供精确值提示。

## 兼容与确定性

本批不升级 GameState v41、存档 envelope v2、云 schema v7 或 SQLite layout v2。画布缓存和物流路径缓存均为运行时只读结构，不进入存档或状态哈希。生产、物流、科研、戴森、离线结算、库存、线路和刷新档位没有改变。

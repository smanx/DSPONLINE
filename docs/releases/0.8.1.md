## 本次范围

- 新账号改为 4～24 位 ASCII 字母、数字或下划线用户名加密码直接注册，不依赖邮件发送器；用户名忽略大小写并保持全局唯一。
- schema v7 为旧账号确定性补充不暴露邮箱的唯一用户名，原邮箱、密码、验证状态、会话、主云存档、三个手动槽、历史修订和排行榜记录均保持原位；旧邮箱登录继续兼容。
- 有效登录会话即可使用主云存档、手动槽 1/2/3、各槽历史恢复和每 10 分钟主存档自动同步，不再要求邮箱验证。
- 排行榜继续要求已验证邮箱及可校验的主云存档。邮件发送器未启用时，邮箱绑定、验证重发和找回密码明确显示尚未开放。
- 注册接口默认同一 IP 每小时最多创建 3 个账号；服务端只信任 Nginx 追加的 `X-Forwarded-For` 最后一跳，避免伪造首项绕过限流。
- 上海 HTTP 页面继续不渲染密码输入框，不会为了备用入口放宽明文凭据边界。

## 本地存档保护

注册、登录、退出和自动上传不会自动下载、替换或删除本地主存档、三个本地手动槽、上一版本备份或自动快照。云端下载与历史恢复仍必须由玩家主动操作；替换当前工厂前继续创建本地回滚快照，冲突不会静默覆盖。

Playwright 会真实建立一份本地主存档并复制到三个本地槽，完成注册、退出和重新登录后逐字比较四份 localStorage 数据，结果完全一致。此次没有修改 `GameState`、存档 envelope、本地存储 key 或迁移链。

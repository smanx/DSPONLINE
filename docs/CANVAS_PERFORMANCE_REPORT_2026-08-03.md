# 画布 P0-P6 性能验证报告（2026-08-03）

## 范围

本轮完成并验证短期/中期画布优化 P0-P6 以及默认关闭的“终局·极限模式”。改动只影响展示、画布派生和本地 UI 偏好，不修改生产、物流、库存、科技、离线收益、GameState 版本或存档内容。本轮没有部署 VPS、下载页或生产版本。

测试存档只在浏览器临时 IndexedDB 副本中读取，未上传云端、未覆盖本地玩家存档。

## 实现摘要

- P0：性能面板按需采样 FPS、帧 P50/P95/最大值、长帧分桶、Worker 耗时/往返、状态传输、Canvas 快照、节点/线路派生、React Flow 对象、DOM、堆内存、刷新间隔和极限模式状态。
- P1：Worker projection/delta 接入当前行星轻量 `CanvasRenderSnapshot`；画布不再因其他星球的完整状态变化而重建。
- P2：拓扑、路线、端口和空间索引缓存；视口变化不再重复全量线路诊断。
- P3：极限模式下关闭普通线路动画、非选中进度动画、普通线路标签和装饰性效果，并降低小地图刷新频率。
- P4：compact/medium/full 真正减少节点组件挂载；选中对象仍保持 full 和即时交互。
- P5：极限模式下按颜色合批 Canvas 线路，React Flow 保留透明命中边；Canvas 不可用时自动回退 SVG。
- P6：视口裁剪、对齐/端口空间索引、拖动期间索引冻结、Canvas 平移 overscan 和小地图低频快照。
- 额外低风险修复：施工托盘和基础制造面板使用引用级 `useMemo` 缓存递归制造计划，避免视口平移触发重复递归规划；性能设置新增英文文案，保持英文界面无中文泄漏。

所有画布实验开关和极限模式开关只写入本地 UI 偏好，不写入 `GameState`，关闭后回退到当前 React Flow 路径。

## 真实存档基准

口径：同一台 Windows Chrome、1440x900、当前行星最密集星球、鼠标滚轮平移，单次采样 3 秒；暂停复测另采样 2 秒。P6 包含极限模式和全部 P1-P6 开关。百分比为 `(P6-基线)/基线`，P95/Task 为下降百分比。

### 最大存档 P0-P6 分阶段（暂停，3 秒）

存档 7.3MB，3,978 实体、8,867 线路，最密星球 373 实体、849 线路：

| 阶段 | FPS | 相对基线 |
| --- | ---: | ---: |
| baseline | 95.90 | 0% |
| P1 | 90.47 | -5.7%（单次测量噪声） |
| P2 | 94.56 | -1.4%（单次测量噪声） |
| P3 | 117.51 | +22.5% |
| P4 | 113.95 | +18.8% |
| P5 | 126.17 | +31.6% |
| P6 | 131.18 | +36.8% |

P1/P2 主要减少运行时派生和跨星球状态影响，短暂停止拖动样本中容易被浏览器调度噪声覆盖；它们不是没有作用，而是不能用单次 FPS 作为唯一证据。P3-P6 是可见收益的主要来源。

### 运行拖动：必须保守解读

运行场景同时包含 Worker 模拟、状态接收、React 更新和画布平移，三次单轮结果并不稳定：

| 存档 | FPS 变化 | P95 变化 | Task 变化 | 结论 |
| --- | ---: | ---: | ---: | --- |
| 4.9MB | 47.0 -> 36.0（-23.5%） | 76.5 -> 125.1ms（+63.5%） | +41.0% | 本轮变差，不能宣称运行收益 |
| 5.5MB | 2.8 -> 12.3（+336%） | 729.9 -> 389.3ms（-46.7%） | -54.4% | 基线极低，改善方向正确但不稳定 |
| 7.3MB | 4.7 -> 8.9（+88.8%） | 681.2 -> 549.1ms（-19.4%） | -38.6% | FPS 提升但最大帧 681.2 -> 1,063.5ms，仍不达标 |

运行模式绝对 FPS 仍没有达到目标 30 FPS，且 4.9MB 档出现回退。Canvas 绘制本身每次约 0.1～0.3ms，剩余瓶颈在运行时 Worker 状态处理、模拟结果复制、递归计划和 GC，不应继续把问题归因于 Canvas raster。

## 未达标项和后续风险

1. 终局极限模式运行时尚未达到 30 FPS 目标，不能发布为强制默认行为。
2. 运行场景的主要剩余热点是 Worker 状态处理、模拟结果发布和递归制造计划；应在不影响生产确定性的前提下继续做增量状态传输和计划缓存基准。
3. 本轮没有执行独立的长时间 600 秒状态哈希/库存守恒对照；Canvas 代码不写 GameState，已有单元和专项 E2E 覆盖回退、交互和不写存档字段，但发布前仍应补运行态长测。
4. Canvas/WebGL 失败回退已在 Chrome 通过；移动 WebView 的 Canvas 稳定性仍需真机验收。

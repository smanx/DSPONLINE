## 第二阶段：超终局优化和实验开发

### A. 先建立可重复基准

为真实存档建立只读基准工具，至少输出：

- 1 秒、5 秒、60 秒、600 秒模拟耗时
- 单段与分段模拟状态哈希
- 生产、传送带、物流、量子、电力、戴森、历史、状态复制和保存各阶段耗时
- 主线程长任务、Worker 耗时、序列化耗时和数据传输字节数
- 实体、传送带、物流站、在途路线、量子库存和各星球分布
- 物资总量、载具、翘曲器、在途货物和库存守恒结果

每次报告必须注明测试时间、提交 SHA、Node/浏览器版本、设备和开关状态。不能把历史输出冒充本次结果。

### B. P3 保存路径

保留现有“相同且已验证状态跳过重复保存”的正确性条件：

- 状态 revision 或权威对象变化时不得跳过。
- 上次写入失败、读回失败、主键缺失时不得跳过。
- 保存请求必须单任务合并，禁止并发写入覆盖新状态。
- 主存档、备份、自动快照和云同步必须继续守恒。

在真实存档上补充测试：

1. 首次保存、状态变化后保存、重复保存分别测量。
2. 自动快照同时发生时测量主线程阻塞。
3. 连续 30 分钟自动保存，验证没有重复快照、旧 revision 覆盖新 revision 或内存持续增长。
4. 保存期间刷新、关闭、恢复、导出和云上传均能读回正确状态。
5. 如确认自动快照仍造成尖峰，可让快照复用已生成的序列化结果或在主存档成功后后台排队，但不得降低读回校验和急救镜像保护。

### C. 传送带和运行时低风险优化

继续优化传送带运行阶段，但只允许等价优化：

- 长期空仓、满仓或无有效输入输出的线路跳过本步无意义工作。
- 按来源、目标、物品、优先级和容量预编译线路分组。
- 拓扑只在端点、等级、堆叠、优先级或线路形态变化时重建。
- 运行数据、几何数据和 UI 观测数据分离。
- 使用数字索引、预分配数组和稳定对象，减少每秒 Map、数组和临时对象创建。
- 保留旧公平分配顺序和 legacy 状态哈希 oracle。

验收目标是稳定状态传送带阶段继续下降，同时：

- 产量、库存、线路流量、优先级、公平性和状态哈希一致。
- 在线、离线、分段、高倍速、暂停恢复和存档重载一致。
- 不得用降低模拟精度、丢弃线路或截断库存换取速度。

### D. P4 增量 Worker 协议

当前真实存档在 1 秒内有超过 90% 的实体/线路变化，不能直接采用“变化对象全量 JSON”作为最终方案。

开发方向：

- 不把完整 `planetTrays`、生产历史、统计、量子运行时或其他大字段塞进每个增量包。
- 按字段和子系统维护 dirty 标记，而不是按整个实体对象重新 JSON 序列化。
- 当前星球、选中建筑、告警和统计使用独立 UI 投影。
- 变化比例过高时自动回退完整状态，不得发送比完整状态更大的增量。
- 带 `baseRevision/nextRevision` 的增量必须拒绝旧响应覆盖新状态。
- 注册表、暂停、保存、离线结算和命令边界建立明确同步点。

P4 默认必须继续关闭。只有同时满足以下条件才允许在候选包中保留实验开关：

- 增量包 P95 小于完整状态包。
- 主线程 GC 和长任务确实下降。
- 主线程、实时 Worker、纯挂机、离线 Worker 状态哈希一致。
- 断电、原料不足、堵塞、物流尾货、量子库存和内容包更新均守恒。
- 协议失配能安全回退完整状态。

### E. P5 批量传送带绘制

使用真实存档至少在 `prairie`（655 条）和 `salt`（639 条）测试，确保实际超过当前 600 条门槛。`ashen` 的 564 条线路不能作为 P5 真正启用场景。

对比默认 SVG/React Flow 与批量线路层：

- FPS、P95 帧耗时、超过 50 ms 长任务数量。
- 线路动画、选中、拖动、拉线、端口命中、缩放和视口裁剪。
- 桌面宽屏、窄屏、手机横屏/竖屏、80%-200% 字体倍率。
- 开启和关闭实验开关后状态哈希、存档和产量不变。
- 连续 30 分钟内存和对象数量不持续增长。

批量数据体积下降不能直接当作 FPS 提升。没有同设备、同存档、同交互场景的实际对比，就只能报告“数据量减少”，不能报告“性能提升百分比”。

### F. P6 多 Worker

保留默认单权威 Worker。多 Worker 只能作为候选实验：

- 先实现确定性分区、固定顺序合并和明确模拟边界。
- 覆盖传送带公平分配、物流伙伴匹配、运输机/运输船、翘曲器、量子库存、电力和在途路线。
- 比较 1、2、4、8 Worker 的实际完整模拟，不得只用扫描探针宣称收益。
- 比较主线程传输、结构化克隆、合并和 GC 后的总耗时。
- 桌面最多实验 4 Worker；移动端默认 1 Worker。
- 只有真实完整模拟 P95 墙钟收益超过 15%，且状态哈希和守恒全部通过，才允许保留候选实验。

不能因为理论探针 4 Worker 快约 70% 就直接打开正式路径。

### G. 终局离线和长期稳定性

使用同一真实存档测试：

- 在线 1 倍、4 倍、12 倍各 30 分钟。
- 连续 2 小时稳定运行。
- 离线 1 小时、8 小时、24 小时、7 天、30 天。
- Worker 每 50-100 ms 主动让出线程，进度、剩余时间和取消按钮真实可用。
- 无法证明稳定时退回精确模拟，不能粗暴放大时间步长。

门禁：

- 不出现持续模拟积压。
- 内存进入平台期，不持续增长。
- 不出现重复产出、物资丢失、路线重复结算或库存负数。
- 单段和分段结果状态哈希一致。
- 暂停期间不补算暂停时间。
- 保存、重载、云同步和导出后仍可恢复。

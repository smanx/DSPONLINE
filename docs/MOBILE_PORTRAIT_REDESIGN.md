# 手机竖屏 UI 与交互重设计规格

> 规格日期：2026-07-23
> 状态：阶段 0-3 已在本地 `0.6.0` 候选实现；阶段 4 真机、反馈与默认切换待完成
> 主要目标：360-430 CSS px 宽度的触屏竖屏网页版/PWA
> 次要目标：手机横屏、600-899 px 平板和窄窗口
> 基线：线上仍为 `0.5.0` 经典手机界面；本地通过 `?mobileUi=next` 试用新版并保留 `legacy` 回退，自动化证据见 `artifacts/qa/mobile-next-*` 与 `mobile-stage2/3/7-*`

## 1. 结论

手机版不应继续采用“把桌面三栏、横向工具条和底部施工托盘压进 390 px”的方案。推荐把手机端定义为一套共享游戏规则、共享领域组件、但拥有独立导航壳层和信息层级的界面：

1. 工厂画布始终是手机主场景，默认只保留 52 px 顶部状态栏和 60 px 底部主导航。
2. 建造、物资、检查器属于保留画布上下文的底部抽屉。
3. 科技、统计、配方、星图等属于真正的全屏工作区，不再让施工托盘常驻其底部。
4. 节点点击先出现 88-104 px 的上下文摘要，不再立即遮住半个画布；详细检查器再由玩家上拉或点击展开。
5. 桌面的横向主从布局在竖屏改成“列表页 -> 详情页”，不依靠横向滚动展示主要内容。
6. 所有必要操作必须有可见按钮；长按、双击和滑动只能作为快捷方式，不能成为唯一入口。
7. 默认字号和触控目标整体上调，通过隐藏次要信息与分层展示控制密度，不再依靠 7-10 px 文本维持版面。

这次重设计不修改生产规则、存档结构、模拟频率或桌面操作语义。移动 UI 状态应保持瞬时，不能写入 `GameState`。

### 2.2 390x844 实测

| 项目 | 当前值 | 影响 |
| --- | ---: | --- |
| 全局顶栏 | 52 px | 仍显示品牌，但没有常驻暂停按钮 |
| 行星导航 | 44 px | 三颗行星同时压缩，名称和状态只能使用极小字号 |
| 画布工具条 | 323x34 px | 10 个 32x32 控件常驻，几乎占满横向空间 |
| 施工托盘 | 96 px | 在画布和所有全屏工作区中始终存在 |
| React Flow 可用高度 | 644 px | 还会被工具条、教学卡、提示和上下文面板覆盖 |
| 半屏抽屉 | 405 px | 一次打开即遮住约 48% 视口 |
| 全屏工作区范围 | y=52 至 y=748 | 与工作区无关的顶栏和施工托盘固定占用 148 px |
| 默认 100% 下小于 12 px 的可见文本 | 约 93% | 中文说明、状态和按钮标签难以快速读取 |
| 低于本方案 44 px 触控目标的首屏控件 | 约 90% | 这是设计目标审计，不等同于正式 WCAG 判定 |

典型触控尺寸包括：顶部按钮 32x38、画布工具 32x32、React Flow 缩放按钮 26x26、施工数量按钮约 31x21、施工模式按钮约 30x22。200% 字体下虽然文字变大，但顶栏、行星条和施工托盘会同步增高或拥挤，信息层级没有重排，仍会出现截断和相互遮挡。

### 2.3 根因

问题不是单个按钮的 CSS 数值，而是以下结构叠加：

- 桌面信息架构被直接缩小。顶部工作区入口、两侧栏、横向行星条、横向画布工具和底部施工托盘仍同时存在。
- 高频操作分散在顶部、底部、画布节点、半屏抽屉和更多菜单，玩家需要不断改变手指位置。
- 节点单击立即打开半屏检查器，查看设备与平移画布相互打断。
- 科技树、配方和蓝图仍采用桌面横向主从结构，竖屏只能看到局部或出现大量空白。
- `max-width`、横屏高度和 `pointer: coarse` 同时承担布局与输入能力判断，窄桌面、平板和触屏电脑容易进入不合适的组合。
- 移动规则散布在多轮媒体查询中，后面的字体倍率修复继续覆盖前面的手机高度，局部修改难以推断最终结果。
- 视觉密度主要通过缩小字号实现，而不是通过优先级、折叠和导航层级实现。

## 3. 设计目标与边界

### 3.1 五个核心任务

竖屏首页必须优先支持以下任务：

1. 看清工厂状态并平移、缩放和定位。
2. 选择建筑或线路，快速读懂停机原因并进行常用操作。
3. 选择设备、设置数量并在画布放置或扩建。
4. 从一个端口连接到另一个端口，并明确知道成功或失败原因。
5. 查看物资、开始科研和进入其他管理工作区。

### 3.2 非目标

- 不重做桌面 UI。
- 不修改 `GameState`、配方、科技、产量、物流或离线模拟。
- 不以减少玩法入口的方式简化手机端，所有桌面能力仍需可达。
- 不取消现有双指缩放、56 px 合法端口吸附、低性能 LOD 和横竖屏世界中心保持。
- 不把关键操作改成只有长按、双击或隐藏手势才能完成。

## 4. 移动信息架构

### 4.1 三层界面

| 层级 | 内容 | 呈现方式 | 是否保留画布上下文 |
| --- | --- | --- | --- |
| 主场景 | 工厂画布 | 顶部状态栏 + 画布 + 底部主导航 | 是 |
| 伴随面板 | 建造、物资、检查器、警报、画布工具 | `peek / half / full` 底部抽屉 | 是 |
| 工作区 | 科技、统计、配方、星图、蓝图、戴森、战役、银河、运营、建筑制造中心 | 移动全屏页 | 否，底层画布冻结 |

目录选择器、确认框和设备快捷操作属于第四种短暂覆盖层，只覆盖当前层级，不改变主导航位置。

### 4.2 顶部状态栏

默认高度为 `52px + safe-area-inset-top`。品牌名称只在主菜单展示，工厂内顶栏用于实时状态：

- 左侧：当前行星按钮，显示行星名、代码和下拉图标；点击打开行星切换抽屉。
- 中间：供电百分比状态。正常为绿色，供电不足为黄色，停电为珊瑚色。
- 右侧：始终可见的暂停/继续按钮和警报按钮。
- 小于 360 px 时供电状态只保留图标与百分比，不隐藏暂停。
- 工作区打开时，同一位置替换为返回按钮、工作区标题和一个页面级主操作。

当前手机顶栏中不可达的暂停操作必须恢复为一键可达。设置、云账号和其他工作区不再挤入顶栏。

### 4.3 底部主导航

默认高度为 `60px + safe-area-inset-bottom`，固定五项：

| 入口 | 行为 |
| --- | --- |
| 工厂 | 返回画布并关闭非必要抽屉；再次点击可回到最近画布中心 |
| 建造 | 打开建造抽屉，默认停在上次分类与模式 |
| 物资 | 打开当前行星物资抽屉 |
| 科研 | 打开移动科技工作区 |
| 更多 | 打开工作区总览 |

检查器不占一个永久导航位。玩家点击节点或线路后，检查器以上下文摘要出现。

### 4.4 更多工作区总览

更多页采用单列分组列表，不使用只有图标的小菜单：

- 生产：生产统计、生产管理、配方图鉴、网络诊断、工业规划。
- 扩张：星图、星际工业、戴森规划、银河网络。
- 工具：主线任务、蓝图库、建筑制造中心、警报与成就。
- 系统：存档、账号、设置、内容包、诊断反馈、保存并返回主菜单。

每行至少 52 px，包含图标、名称、单行状态和可选徽标。最近使用的三个工作区置于顶部分组，但不改变完整目录。

## 5. 竖屏主画布

### 5.1 默认线框

```text
┌────────────────────────────────────┐
│ 澄海 I ▾     ⚡ 100%       暂停  警报 │ 52 + safe top
├────────────────────────────────────┤
│ [任务 2/13  获取第一份矿石       >] │ 可折叠 40
│                                    │
│                                    │
│            工厂无限画布             │
│                              [工具] │ 44x44
│                                    │
│                                    │
│ [风力涡轮机 · 正常 · 300 kW   查看] │ 选中后出现 88-104
├────────────────────────────────────┤
│ 工厂    建造    物资    科研    更多 │ 60 + safe bottom
└────────────────────────────────────┘
```

在 390x844 下，无抽屉时画布区域约为 732 px，高于当前 React Flow 的 644 px；同时取消独立行星条和常驻 323 px 工具条。教学任务默认以单行浮层呈现，完成一次交互后自动收起为仅图标和进度的 44 px 按钮。

### 5.2 画布工具

默认只常驻一个 44x44 的“工具”按钮和必要时出现的模式状态条。工具抽屉内提供：

- 浏览、逐点多选、布局移动、生产区域。
- 蓝图、连续网络、自动整理、布局撤销。
- 撤销、重做、定位全部、画布书签。
- 小地图仅在平板或玩家主动打开时显示。

撤销/重做不再常驻为两个 32 px 图标。放置、回收、升级等可逆操作完成后，优先显示带“撤销”的 5 秒操作条。

### 5.3 画布模式

```ts
type MobileCanvasMode =
  | "browse"
  | "place"
  | "connect"
  | "select"
  | "layout"
  | "region";
```

任一时刻只允许一个主模式。模式开始后在底部导航上方显示 52-60 px 的状态条，明确展示当前对象、下一步和取消按钮。进入另一模式前必须先结束当前模式，避免“选中、放置、连线、区域”同时生效。

### 5.4 触摸语义

| 手势 | 浏览模式 | 其他模式 |
| --- | --- | --- |
| 单击空白 | 清除选择或关闭摘要 | 提交当前合法操作，非法时说明原因 |
| 单指拖空白 | 平移画布 | 平移画布，区域模式除外 |
| 双指 | 平移并缩放 | 保留现有安全规则，取消第一指未提交动作后接管画布 |
| 单击节点 | 选中并显示摘要 | 选择扩建、连接或多选目标 |
| 拖动节点 | 默认平移，不移动节点 | 仅在布局模式移动节点 |
| 长按节点 | 打开快捷操作 | 作为加速入口，不承担唯一功能 |
| 单击端口 | 开始或完成连接 | 连接模式按物品与方向校验 |
| 单击线路 | 选中并显示线路摘要 | 多选模式加入/移出选区 |

将节点移动收进显式“布局模式”可以减少竖屏上最常见的误拖。长按快捷菜单继续保留，但摘要栏内必须有可见的“更多操作”按钮。

## 6. 上下文检查器

### 6.1 三段高度

- `peek`：88-104 px，只显示名称、状态、关键产量/功率、停机原因和“查看”。
- `half`：约 52dvh，提供概览、输入输出、设置三个页签和三项高频操作。
- `full`：顶部状态栏到底部导航之间的全部高度，用于物流站、多槽配置和复杂批量操作。

点击节点默认只打开 `peek`。点击摘要或向上拖动进入 `half`；再次上拉进入 `full`。向下滑动逐级收起，点击画布空白直接关闭 `peek`。

### 6.2 内容优先级

检查器首屏按以下顺序组织：

1. 状态与停机原因。
2. 当前配方、进度、输入和输出。
3. 三个上下文主操作，例如“补充燃料”“切换配方”“增加设备”。
4. 高级电网、优先级、物流槽、增产和回收设置。

复杂设备不再把所有字段堆在一个滚动页中：

- 生产设备：概览 / 输入输出 / 配置。
- 电力设备：概览 / 燃料与电网 / 优先级。
- 物流站：概览 / 物流槽 / 载具与路线。
- 线路：概览 / 路由 / 优先级与监测。
- 多选：选择摘要 / 批量配方 / 批量升级与回收。

危险操作放入“更多”页底部，使用全宽 48 px 按钮并二次确认；不能与日常操作并排成小图标。

## 7. 建造流程

### 7.1 建造抽屉

```text
┌────────────── 画布仍可见 ──────────────┐
│                                        │
├─────────────── ─ ─────────────────────┤
│ 建造                         搜索  关闭 │ 52
│ [部署] [制造] [载具]                   │ 44
│ 全部  最近  能源  生产  物流  戴森       │ 横向分类 44
│ ┌─────────┐ ┌─────────┐ ┌─────────┐   │
│ │ 风力     │ │ 采矿机   │ │ 电弧炉   │   │
│ │ 库存 x3  │ │ 库存 x2  │ │ 库存 x3  │   │
│ └─────────┘ └─────────┘ └─────────┘   │
├───────────────────────────────────────┤
│ 工厂    建造    物资    科研    更多    │
└───────────────────────────────────────┘
```

推荐使用“部署 / 制造”分段模式，取消当前卡片内 36 px 小锤子和左侧 21 px 数量矩阵的嵌套操作：

- 部署模式：卡片点击选择库存中的设备，库存为 0 时禁用并可跳转制造。
- 制造模式：卡片点击执行制造，先展示实际消耗预览；递归手搓规则保持不变。
- 载具模式：物流运输机和运输船独立展示。
- 390 px 默认三列，125%/150% 根据容器降为两列，200% 降为单列或两列大卡。
- 卡片最小高度 84 px，整张卡是一个主触控目标。

### 7.2 放置状态条

选择设备后建造抽屉关闭，画布底部出现状态条：

```text
[采矿机 x2]  [−] [2] [+]  [连续放置]  [取消]
```

- 数量不再使用四个 21 px 预设按钮，改为 44 px 步进器；长按加减可连续变化。
- 手机没有 Ctrl，因此提供显式“连续放置”切换。
- 合法目标高亮，非法位置在状态条中解释原因。
- 矿机、抽水站和原油萃取站直接高亮兼容资源节点。
- 放置成功后状态条显示剩余库存，并提供一次撤销。
- 库存耗尽时退出放置模式，不吞掉已完成操作。

### 7.3 连线流程

端口视觉尺寸建议为 22-24 px，实际命中区域至少 48 px；命中扩展必须通过透明 hit slop 或 React Flow `connectionRadius` 完成，不能 `scale()` 真实 handle 造成线路坐标偏移。

1. 点击输出端口，状态条显示“铁矿石输出：请选择目标设备”。
2. 所有合法输入端口强化显示，不合法端口弱化但仍可点出原因。
3. 点击目标端口完成连接；56 px 合法吸附继续生效。
4. 成功显示等级、预计吞吐和撤销；失败显示“物品不匹配 / 方向错误 / 槽位已满 / 施工库存不足”等具体原因。
5. 拖拽连线继续作为熟练用户快捷操作，但两次点击是手机主路径。

## 8. 物资与行星

### 8.1 物资抽屉

当前资源栏把光标载荷、戴森系统、物资托盘和任务摘要放在一个长列表中。手机端应拆为：

- 顶部：光标载荷和“全部放回当前行星”。
- 主体：当前行星库存，支持搜索、按数量/类别排序和物品行点击拿取。
- 次级页签：随身载具、戴森摘要。
- 行星单种上限属于设置，不占物资首屏。
- 物资已拿起时，底部导航“物资”显示数量徽标和高对比状态；点击即进入可放回区域。

物品行高度至少 48 px，名称和数量使用两端对齐。拖放可保留，但点击拿取、点击放回必须完整覆盖同一能力。

### 8.2 行星切换

点击顶部行星按钮打开半屏抽屉：

- 每个已殖民行星一行，显示名称、环境、设备数、供电率和异常数。
- 未殖民行星不挤在主画布顶端，只在星图中展示；已经解锁但未殖民可在列表尾部显示入口。
- 切换前若光标携带普通物资，明确标注“将随玩家带往目标行星”。
- 切换后保持世界中心、缩放、选择和面板状态的现有规则。

### 9.1 统一模板

- 移动端主从布局使用页面导航，返回时恢复列表滚动位置和筛选条件。

## 10. 返回、抽屉与浏览器行为

### 10.1 单一导航状态

建议将当前多个布尔工作区和 `mobilePanel + mobilePanelStage` 收敛为移动控制器：

```ts
type MobileRoute =
  | { kind: "factory" }
  | { kind: "hub" }
  | { kind: "workspace"; id: WorkspaceId; subview?: string };

type MobileOverlay =
  | { kind: "sheet"; id: "build" | "inventory" | "inspector" | "planet" | "alerts" | "tools"; snap: "peek" | "half" | "full" }
  | { kind: "modal"; id: "catalog" | "confirm" | "quick-actions" }
  | null;
```

每一时刻最多存在一个路由、一个抽屉和一个模态层。桌面仍可继续使用现有工作区状态，移动控制器只负责映射和关闭顺序。

### 10.2 返回顺序

浏览器返回、Android 返回和界面返回按钮使用同一规则：

1. 关闭目录选择器或确认框。
2. `full` 抽屉回到 `half`，`half` 回到 `peek` 或关闭。
3. 取消当前画布模式并保留已提交操作。
4. 详情页返回列表页并恢复滚动位置。
5. 工作区返回工厂并恢复世界中心。
6. 工厂根页面再次返回时才显示“保存并返回主菜单”确认。

使用 `history.pushState` 表达工作区和详情页，避免用户按系统返回直接退出网页。进入后台、`pagehide` 和返回主菜单的保存规则保持不变。

### 10.3 抽屉手势

- 抽屉高度使用 `peek / half / full` 三个明确吸附点，不使用任意停留位置。
- 只有把手和抽屉标题栏负责改变高度；内容列表的普通纵向滚动不触发关闭。
- 当内容滚动到顶部后，从标题栏向下滑才允许收起。
- 点击遮罩关闭 `half`，`full` 先退到 `half`；进行破坏性确认时遮罩不关闭。
- 打开输入法时根据 `visualViewport` 把输入和主操作保持在可见区域，底部导航可暂时隐藏。

## 11. 视觉、尺寸与可访问性

### 11.1 尺寸令牌

| 令牌 | 默认值 | 规则 |
| --- | ---: | --- |
| 顶部状态栏 | 52 px | 另加顶部安全区 |
| 底部主导航 | 60 px | 另加底部安全区 |
| 主触控目标 | 48x48 px | 建造、确认、放置、返回、暂停 |
| 普通图标按钮 | 最小 44x44 px | 相邻按钮间距至少 4 px，推荐 8 px |
| 紧凑次级目标 | 最小 36x36 px | 只用于非危险、非高频且有足够间距的操作 |
| 页面左右边距 | 12-16 px | 320 px 回退到 10 px |
| 抽屉圆角 | 8 px | 只用于真正的抽屉、模态和重复项 |
| 动画时长 | 120-180 ms | 减少动态效果时改为接近即时 |

### 11.2 字体

- 页面标题 18 px，工作区标题 16 px，正文 14 px，次级信息 12 px，徽标/物品符号可为 11 px。
- 默认 100% 下，玩家需要阅读的中文不得低于 12 px。
- 字体不随视口宽度缩放，只响应玩家的 80/100/125/150/200% 设置。
- 125% 以上通过减少列数、换行、折叠次要字段和增加内容滚动适配，不通过截断主要按钮标签适配。
- 150%/200% 进入“大字密度”：建造网格降列、统计行改为单列、页签允许换成下拉切换；顶栏和底栏只做有限增高，不能像当前方案增至 148-166 px 的施工托盘。

### 11.3 颜色与状态

保留桌面品牌语言，但明确功能分工：

- 青色：可交互、选中、连线待定。
- 绿色：成功、运行正常、合法连接。
- 黄色：建造、等待、库存不足或低供电。
- 珊瑚色：错误、停机、危险操作。
- 蓝色：信息与跨星球状态。
- 中性黑绿表面只作背景，不能让所有状态都依赖同一青绿色。

状态不能只靠颜色表达，必须配合图标和短文本。所有图标按钮提供 `aria-label`，陌生图标在支持悬停的设备上提供 tooltip。

### 11.4 节点与语义缩放

- 默认缩放下节点主名称至少 13 px，状态和关键数值至少 12 px。
- 缩放较小时切换为真正的紧凑 LOD，只显示图标、名称、状态和主要产量；不要继续缩小全部文字。
- 选中节点临时提高信息层级，详细缓存和设置仍放入检查器。
- 节点和端口尺寸变化不能使用会破坏 React Flow handle 坐标的视觉 `scale()`。
- 线路继续位于节点下层，扩大命中区不能遮住节点卡片。

## 12. 响应式策略

布局和输入能力分开判断：

- `compact portrait`：宽度小于 600 px，采用本规格完整竖屏布局。
- `compact landscape`：高度小于 560 px 且宽度小于 1100 px，底部抽屉改为左右侧抽屉，主导航可保持底部 56 px。
- `medium`：600-899 px，画布仍使用移动导航，但检查器可成为 360 px 右侧覆盖层，建造网格提升为四列。
- `desktop`：900 px 以上优先沿用当前桌面三栏；触屏只改变命中尺寸和手势，不自动改成手机信息架构。

JS 只在需要替换组件结构时使用与 CSS 相同的 `matchMedia` 查询。`pointer: coarse` 仅控制触摸手势、吸附和命中区，不能独自决定页面布局。

横竖屏切换必须继续保持：

- React Flow 世界中心与缩放。
- 当前行星、选择和画布模式。
- 打开的工作区、详情层级、抽屉种类和合理的吸附点。
- 正在编辑的表单草稿，但不能自动提交。

- 100% 字体下，所有必要中文文本至少 12 px。

- 合法端口吸附半径保持至少 56 px，真实 handle 与线路端点保持对齐。

### 15.3 隐私友好指标

只记录白名单聚合事件，不记录坐标、实体 ID、按钮文案或存档内容：

- `mobile_nav_open`
- `mobile_sheet_open` / `mobile_sheet_snap`
- `mobile_build_select` / `mobile_place_success` / `mobile_place_cancel`
- `mobile_connect_success` / `mobile_connect_fail`
- `mobile_inspector_expand`
- `mobile_workspace_open`
- `mobile_back_action`

比较指标：

- 新玩家首次完成采矿、放置和连线的时间。

- 连线失败后 30 秒内成功的比例。
- 节点点击后展开完整检查器的比例，判断 `peek` 是否提供了足够信息。
- 工作区打开后 3 秒内关闭的比例，识别误触入口。
- 低端手机的 FPS 降级占比和工作区打开耗时。

### 15.4 玩家验证

从明确反馈过手机问题的玩家中邀请 6-10 人，至少覆盖小屏 Android、主流 Android 和 iPhone。不给操作提示，让玩家完成：

1. 找到铁矿并采集。
2. 制造并放置一台设备。
3. 把矿脉连接到生产设备。
4. 找出一个设备停机原因并修复。
5. 开始一项科技并返回工厂。
6. 切换行星并查看物资。

记录完成率、耗时、误触、回退次数和口头困惑。实现阶段不能只依赖截图“看起来更大”。

## 16. 实施前固定的产品决策

本规格推荐直接采用以下默认值：

1. 底部五项固定为“工厂 / 建造 / 物资 / 科研 / 更多”。
2. 节点单击默认打开 `peek`，不直接打开半屏检查器。

# 2026-07-26 稳定性复盘

## 结论

`1.0.3` 基线的存档、确定性模拟、物流、科研、戴森、云槽和发布工具自动化均未发现新的数据损坏问题。本轮确认并修复三个与长期运行或异常浏览器环境有关的问题；改动仅涉及认证凭据容错、服务端过期记录回收和 PWA 更新监听器，不升级玩法状态或存档格式。

本轮只修改本地工作区，没有提交、推送或部署香港/上海节点。

## 已修复问题

### 1. 存储异常导致云登录立即失效

原实现捕获 `localStorage.setItem()` 失败后声称当前页面仍可使用会话，但 `getCloudToken()` 只读取持久层，因此隐私模式、受限 WebView 或存储异常下，注册/登录成功后的下一次认证请求会丢失 token。

现在正常存储仍是跨标签共享的权威来源；存储写入失败或突然不可读时使用当前页面的最后已知 token。退出、账号删除或当前会话撤销时，即使删除持久 token 失败，内存中的显式空值也会阻止旧 token 复活。

### 2. 服务端认证与限流记录长期累积

原服务只在过期 token 再次被使用、或同一用户再次申请动作 token 时删除记录；不再访问的过期会话、邮箱验证、密码重置记录和限流 key 会长期保留。

现在服务启动时清理一次，之后在每分钟持久化前清理过期或孤立认证记录；认证与注册限流桶按各自窗口回收。清理函数只按明确的 `expiresAt <= now`、非法记录或不存在所属用户删除，仍有效记录保持原样。

### 3. PWA 更新监听器重复累积

原“立即更新”每次点击都注册新的 `controllerchange` 监听器。waiting worker 激活较慢或用户重复点击时，未来一次控制器切换会触发多个刷新回调。

现在一个页面生命周期只注册一个一次性刷新监听器；重复点击仍可再次发送 `SKIP_WAITING`，但不会增加回调数量。

## 共享 UI 架构

- `WorkspaceFrame`：工作区模态语义、背景 inert、焦点圈定与恢复。
- `ShellSafeArea`：由壳层动态变量提供上下安全区，禁止工作区再次写死 68/108px。
- `ModalNavigationTransition`：移动 modal → workspace/sheet 的单次 history replace。
- `ResponsiveTabBar`：横向滚动、边缘提示和完整短标签。
- `FormDraftScope`：页面内存中的非敏感草稿命名和主动清除边界；密码始终 `sensitive`。

共享组件必须保留现有视觉和业务组件，不写入 GameState，不改变移动/桌面模拟路径。

## 1. 目标与不变量

1. 保留已完成的 1.0.42 UI 全面复核：动态壳层安全区、移动端原子导航、模态背景 inert/焦点恢复、统计语义、亮暗主题对比度、80%～200% 字号、44px 触控目标、中文组合输入与教程内容 revision。
2. 合入最终 1.0.41 香港 P0 热修：云正文定向回收和微型黑洞显式运行字段，不回退其生产修复。
3. 修复合法 35 MiB 本地存档首次写入超过 15 秒时，被同一 writer 的过期租约误判为跨标签页覆盖。
4. 扩展增产剂缓存上限，允许 100 万预设和 1～1 亿正整数自定义值，不改变倍率、消耗或补充规则。
5. 允许明确的 `speedrun` 存档在无限矿物模式下提交速通正式榜，并公开显示“无限矿物”标签；普通银河榜和模式隔离不变。
6. 修复没有有效纯挂机恢复会话时，“未提交时间扭曲预算”阻塞普通离线结算的问题；真实墙钟时间转入普通离线，高倍率未提交预算不得重复发放。
7. 保持 GameState v46、save envelope v2、cloud schema v7、SQLite layout v2 和 IndexedDB records 结构不变，不新增旧存档必填字段。

## 2. 需求与实现边界

### 2.1 UI 全面复核

- 全屏工作区使用壳层实时顶栏/底栏安全区；桌面和移动端在 80%、100%、125%、150%、200% 字号下可见、可滚动、可点击。
- 手机命令面板使用一次原子导航替换，避免关闭面板触发第二次返回。
- 工作区打开时只把被覆盖的工厂内容设为 inert；可见导航、嵌套确认框和 Portal 仍可操作，关闭后恢复触发点焦点。
- 普通文字输入保护 composition 和页面内草稿；密码不共享、不持久化、不记日志。
- 教程显示应用版本，但进度迁移由独立内容 revision 决定。

### 2.2 35 MiB 本地存档与冲突恢复

- 同一 `writerId + fencingToken` 即使心跳因大档解析、结构化复制或 IndexedDB 准备延迟而过期，也可以在写事务内续租；owner 或 fencing token 变化仍视为真实接管并拒绝覆盖。
- 冲突处理返回结构化失败分类：存储不可用、活动 writer、租约丢失、候选缺失/损坏、基线变化、读回失败等。
- “当前为空、候选有效”时明确显示当前为空、推荐采用候选；保留当前按钮明确说明会保留空状态。
- 选择版本后先写入，再逐字读回并核对 revision、checksum 和模式；只有全部通过后才清理候选/持久冲突副本并刷新。
- 若写入成功而清理前租约变化，候选继续保留；下一次合法租约可以识别已应用正文、创建本 writer 的新 revision 并完成清理。
- 诊断只包含租约状态、耗时和失败分类，不包含存档正文。玩家附件只做只读核验；自动化使用运行时生成的脱敏 35 MiB 夹具。

### 2.3 增产剂缓存

- 预设为 120、600、3,000、1,000,000；自定义范围 1～100,000,000，只接受十进制正整数。
- 上限只约束已安装喷涂机的增产剂物品容量；既有超额库存不删除，普通生产输入容量不随之扩大。
- 服务端 v33+ 结构校验同步接受新上限，超过 1 亿、0、负数、小数、字符串和其他非法值继续拒绝。

### 2.4 无限矿物速通

- 只有 envelope/state 均明确为 `speedrun`、结构与速通规则校验通过、且不存在 MOD、实验、极限模式等禁止状态时才可提交。
- `resourceMode=infinite` 不再是禁止原因；服务端从权威 speedrun main 云存档派生该标签，不相信客户端自报字段。
- 新 submission 和公开 DTO 包含 `finite | infinite`；历史缺字段记录按 `finite` 兼容，因为旧规则不接受无限资源正式成绩。
- 普通 main、普通手动槽、speedrun 手动槽都不能借此提交或污染榜单。

### 2.5 未提交时间扭曲预算

- 启动前检查纯挂机恢复日志，并区分 `valid`、`committed`、`missing`、`invalid`、`unavailable`。
- 仅普通 main 且日志 checkpoint 指纹匹配时，仍由既有纯挂机恢复流程独占时间线。
- 没有有效会话时，以已保存 GameState 为最后权威检查点：关闭 time warp，清零未提交模拟/墙钟预算和功率运行字段，不改库存、累计产量或缓存。
- `pendingWallSeconds` 与存档后的真实离线时长合并一次并受既有离线上限约束；`pendingSimulationSeconds` 只记录为已丢弃的未提交高倍率债务，不能与普通离线同时结算。
- 自动核验不可用或时间字段无效时显示原因和“恢复检查点并快速结算”；取消保持原始正文、savedAt 和完整待结算区间不变。快速结算失败继续进入既有重试/精确/放弃选择，不静默吞收益。

- 完整 Chromium；Firefox/WebKit 核心旅程；production preview PWA。
- 从新的 clean 固定提交生成 Web、API、source、Android unsigned APK/AAB 和 Windows unpacked 诊断件。
- 生成 source manifest、conditional skip 报告、CycloneDX SBOM、候选 manifest、SHA-256 和 in-toto provenance，并逐项复验。
- 正式 Android/Windows 签名、证书连续性、覆盖升级、低配/真机、Linux systemd/Nginx/备份/灰度仍由 Release Agent 执行。

## 5. 兼容、风险与回滚

- 无存档结构迁移；旧 v46 稠密/稀疏正文直接读取。增产剂旧值和历史速通条目通过默认值兼容。
- 本地冲突失败时保留双方副本；离线恢复失败时保留原正文和待结算区间；云端旧 revision、submission 和排行榜历史均不修改。
- 大档逐字读回会短时增加 IndexedDB I/O 和内存压力，但只发生在保存/冲突恢复边界，不进入模拟帧循环。后续仍需在低配 Windows、Android、PWA 和 35 MiB 真实规模上做发布侧真机验收。
- 未部署时废弃新候选即可。已灰度时只把 Web/API/静态制品切回最后验证过的 1.0.41 不可变版本；不得恢复生产数据库、清空浏览器存储、删除冲突副本、修改云历史或排行榜。

# 行星工厂网络

《戴森球计划》生产流程的 2D 无限画布挂机原型。当前 v23 版本覆盖开局自动化、六色矩阵、戴森云、可规划永久结构、三恒星系工厂、跨恒星物流、银河终局和战役运营系统，不包含机甲角色。

## 当前内容

- 赫利俄斯、北冕座与赫卡忒三个恒星系共六颗行星，各自拥有无限画布、节点布局、小地图、独立电网和物资托盘。
- 独立星图展示恒星类型、距离、行星环境与资源；完成恒星探索科技后消耗矩阵和空间翘曲器建立永久航标。
- 星图新增“星际工业”视图：可为行星指定采矿、冶炼、制造、化工、科研、物流或能源角色，按星系汇总设备、电力、储量和矿脉枯竭预测。
- 行星导航只显示当前恒星系，星图负责跨恒星进入；光标可托住一组物资跨星旅行，其他库存不会瞬移。
- 持续按住铁、铜、石、煤、硅和钛矿脉进行连续手动采集；原油使用原油萃取站，水与熔岩星硫酸海洋使用抽水站。
- 光标点击携带物资，也可以直接把节点产物拖入物资托盘或生产节点。
- 初始施工套装：3 台风机、2 台采矿机、3 台熔炉、3 台制造台、2 台研究站和 10 条传送带。
- 风力涡轮机、火力发电厂、电弧熔炉、制造台 Mk.I、采矿机、矩阵研究站、原油萃取站、原油精炼厂、抽水站、化工厂、微型粒子对撞机和星际物流站。
- 原版早期熔炼、基础零件、蓝色矩阵、等离子精炼、红色矩阵、X 射线裂解、黄色矩阵、紫色矩阵与绿色矩阵配方。
- 熔岩星硅钛矿和硫酸海洋，以及钛合金、处理器、纳米材料、粒子宽带、氘、卡西米尔晶体、量子芯片、奇异物质、引力透镜和引力矩阵完整产业链。
- 建筑制造成本、施工托盘和同类设备机组合并。
- 基础制造的物品页支持立即手搓与最多 20 项持久化手搓队列；队列按真实配方周期推进，缺料或切换行星时会明确等待。
- 配方图鉴显示每台设备的批次速度、输入需求/min 和输出产量/min，并在打开时运行内容数据审计，检查物品、设备、科技和替代配方引用。
- 施工托盘支持 `×1 / ×2 / ×5 / ×10` 批量部署，一次建立对应规模的设备组。
- 三级传送带与分拣器支持低/标准/高优先级、1/2/4 层货物堆叠、实时流量监测、累计运量、拥堵指数、设置复制和连续网络批量升级。
- 线路支持曲线、自动避让、上绕、下绕与手动高度控制点；同端点线路会组成错位线路束，输入/输出端口显示实时占用数。
- 生产统计中的网络总览可搜索并筛选全星区连续网络，显示上下游、综合利用率、瓶颈和容量缺口，并支持多选升级、改道、设置同步和整网回收。
- 可切换吞吐热力图，也可把任意行星的当前缩放与画布位置保存为命名书签后快速返回。
- 单物品储物仓、流体储液罐，以及支持均衡和优先线路的四向分流器。
- 行星与星际物流站支持 5 个独立物品槽；每槽分别配置本地/远程供应、需求或仓储、最低装载率、库存上下限与调度优先级。
- 需求站维护真实在途航次与载具占用；星际站可同时调度本地运输机和星际运输船，并显示航线队列、抵达进度与拥堵指数。
- 星际物流站每船最多运输 100 件物资，恒星系内航程 30 秒，跨恒星翘曲航程 12 秒并消耗站内翘曲器。
- 全局航线表按真实源/汇槽位展示航程、翘曲器、能耗、周期、吞吐和故障原因；可直接调整最低装载率、出口保底、进口上限与调度优先级，并一键定位问题站点。
- 两颗气态巨星拥有不同氢、氘和可燃冰丰度；冰原星支持可燃冰矿脉，光栅石与刺笋结晶迁至北冕座，单极磁石迁至中子星系。
- 火电按电网缺口燃烧煤、原油、高能石墨、精炼油、氢或 600 MJ 氘核燃料棒；风电优先且空载不消耗燃料。
- 设备卡片和检查器显示缺料、堵塞、断电、供电不足、缺燃料等运行状态。
- 选中生产设备卡片即可直接切换配方，输入槽中的原料可以点击取回或拖至其他位置。
- 节点实时跟随鼠标拖动，释放后将布局写入存档。
- 画布支持专用框选模式、`Shift` 多选和整组拖动；选区可批量升级或回收。
- 选区可复制为持久化蓝图，保留设备相对布局、配方、物流配置、内部传送带等级与优先级；点击画布按真实施工库存粘贴。
- 蓝图同时记录选区边界上的外部输入/输出端口，并支持 0/90/180/270 度旋转、水平镜像和按原始配方分组的部署参数。
- 蓝图库显示节点、线路、外部接口、当前行星兼容性和逐项施工缺口；材料不足时可建立施工订单，库存齐备后自动部署。
- 独立戴森球规划工作区支持每个恒星系最多 8 个轨道壳层，并可调整轨道半径、倾角和升交点经度。
- 壳层可手工布置节点、连接框架与规划壳面，也可一键建立 8 节点标准层；运载火箭只建设发射井所在恒星系的结构。
- 结构点先完成节点再完成框架，只有全部边界框架完工的壳面才能吸附太阳帆；尚未建立规划层的旧存档继续沿用结构点容量规则。
- 采矿、生产、加工、科研和物流设备卡片显示绿色工作周期条；连续发电设施只显示实时功率。
- 全部物品库存采用整数结算，机器和运输线内部保留不可见周期进度。
- 蓝色/红色/黄色/紫色/绿色/白色矩阵生产、科研队列、完整科技与建筑制造解锁。
- “星际物流理论”消耗三色矩阵并解锁星际物流站制造。
- “科研速度 I”消耗四色矩阵并将矩阵研究速度提高 25%。
- “科研速度 II”消耗五色矩阵并将矩阵研究速度累计提高至 50%。
- 科技支持按前置关系排队、完成后自动推进，并可从队列移除尚未开始的项目。
- 升级科技补全高效采矿 II/III、物流运输引擎 I/II、物流载荷扩容 I/II、太阳帆轨道寿命 I/II、射线传输效率 I/II 与壳面吸附效率。
- 科技树实时汇总采矿、科研、物流航速、运输载荷、太阳帆寿命、射线接收和壳面吸附倍率；设备检查器使用升级后的真实数值。
- 生产统计工作区汇总物品每分钟产出、消耗、净增量和网络库存，并提供电力负载与设备瓶颈清单。
- 工业规划中心可保存多个目标产量方案，递归反推所需设备、原料、电力与物流吞吐，支持替代配方、行星范围、库存耗尽预测和滚动历史曲线。
- 运营中心统一呈现设备警报、13 项工业成就、模拟设置与本地存档管理；警报可跨行星直接定位故障设备。
- 支持 `1× / 2× / 4×` 模拟速度、性能模式、减少动态效果、可选操作音效和 2/10/30 秒自动保存间隔。
- 科技、配方、统计、星图、戴森规划与运营工作区按需加载；React、画布和游戏核心拆分为独立缓存块。
- 离线进入时显示独立结算报告，汇总新增物资、完成科技、永久结构点与壳面太阳帆。
- 银河终局战役章节追踪无限科研、银河出口、评分与四类出口项目全成就，并可从任务中心直达银河控制台。
- 运营中心提供舒缓 / 标准 / 高压三档工业难度；难度同时影响生产、采矿、物流速度和电网需求，并保留旧存档的标准默认值。
- 工作区支持键盘 `Escape` 关闭、`Space` / `P` 暂停切换，弹出式工作区自动接收焦点并声明可访问的标签页与进度条。
- 主存档支持 JSON 导入导出、立即保存与三个独立本地槽位；兼容 v1-v23 存档迁移。
- 桌面工作区与移动端资源/检查器抽屉。

## 试玩

```powershell

npm run dev
```

## 结构

- `src/game/content.ts`：物品、配方、建筑和制造成本数据。
- `src/game/engine.ts`：确定性生产、电力、缓存和物流模拟。
- `src/game/statistics.ts`：生产速率、电力负载和设备瓶颈统计。
- `src/game/planning.ts`：目标产量递归展开、设备需求、库存续航与方案管理。
- `src/game/alerts.ts`：跨行星设备状态诊断与警报聚合。
- `src/game/difficulty.ts`：工业难度预设与平衡倍率。
- `src/game/progression.ts`：工业成就定义、进度计算与幂等解锁。
- `src/components/FactoryNodes.tsx`：矿脉、机器、发电、仓储、分流与星际物流节点。
- `src/components/GamePanels.tsx`：分行星库存、行星导航、制造、检查器和施工界面。
- `src/components/StatisticsWorkspace.tsx`：生产、电力与瓶颈分析工作区。
- `src/components/StarMapWorkspace.tsx`：恒星系勘探、航线与行星入口。
- `src/components/BlueprintWorkspace.tsx`：框选工具、选区命令、蓝图库与部署反馈。
- `src/components/DysonPlannerWorkspace.tsx`：多恒星壳层、轨道、节点、框架与壳面规划。
- `src/components/OperationsWorkspace.tsx`：警报、成就、设置与存档运营中心。
- `src/components/OfflineReportWorkspace.tsx`：离线生产增量结算报告。
- `src/App.tsx`：无限画布、存档与实时推进。

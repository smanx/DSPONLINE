# 隐私政策

生效日期：2026-07-24

本政策适用于项目维护者运营的 `dsponline.cn`、其官方节点和官方签名客户端。第三方自行部署的实例由其运营者独立负责，本政策不适用于这些实例。

## 本地数据

游戏存档、备份、快照、内容包、界面偏好、本地身份和大部分运行记录默认保存在浏览器或应用本地。除非玩家主动使用云存档、排行榜、反馈功能，或进入工厂触发下述匿名统计，这些数据不会上传到官方服务。

玩家可以通过浏览器站点数据管理、游戏内存档管理或卸载应用删除本地数据。清理浏览器数据可能永久删除未导出的本地存档。

## 官方服务处理的数据

### 匿名在线与使用统计

- 本地随机生成的匿名玩家 ID 和会话 ID；
- 页面访问、进入游戏、允许名单内的功能事件及活跃时长；
- 以区间记录的加载时间、LCP 和静态资源传输量；
- 粗粒度客户端类型和来源类别；
- 服务端对匿名 ID、会话和 IP 地址生成的命名空间 SHA-256 摘要。

官方应用数据库不保存统计请求中的原始 IP 地址、完整 URL 参数、鼠标坐标、按钮文字或游戏存档。Web 服务器和基础设施日志可能为安全、故障排查和滥用防护暂时记录 IP、请求路径、时间和 User-Agent。

### 云账号

- 用户名、显示名称和可选邮箱；
- 使用 scrypt 派生的密码摘要，不保存明文密码；
- 会话和邮箱动作令牌的 SHA-256 摘要；
- 会话时间、设备类别和截断后的 IP 摘要；
- 账号安全操作的最小化审计记录。

### 云存档、排行榜与反馈

- 玩家主动上传的四个云存档槽位、元数据和历史修订；
- 玩家主动提交的排行榜指标、显示名称和赛季记录；
- 玩家主动提交的反馈内容；
- 客户端错误消息以及构建版本、页面位置、客户端类别等诊断信息。

不要在反馈正文中填写密码、令牌、身份证件、支付信息或其他不必要的个人信息。

## 使用目的

上述数据只用于提供账号、云存档、排行榜、活动、更新、故障排查、安全审计、滥用防护和聚合运营统计，不出售个人信息，也不用于第三方广告画像。

## 保存期限

- 登录会话默认最长 30 天；邮箱验证和密码重置令牌默认 30 分钟。
- 匿名分析会话记录保存 30 天；按日聚合指标和用于累计去重的匿名摘要可能在服务运营期间保留。
- 每个云存档槽位最多保留 20 个历史修订。
- 安全审计最多保留最近 2,000 条，反馈和客户端错误分别最多保留最近 1,000 条。
- 账号和关联云数据保留到玩家主动注销账号或服务终止。
- 加密备份按运维轮换策略自动过期；账号注销后，已存在备份中的副本会随备份轮换删除，而不会立即改写历史备份。

## 数据提供与跨境

官方服务可能使用服务器托管、加密备份和邮件发送供应商。绑定邮箱并请求验证或重置时，邮箱地址和一次性动作令牌会发送给配置的邮件服务商。香港与上海节点使用独立数据库；玩家访问不同节点时，数据处理地点可能不同。

除提供服务、遵守法律或处理安全事件所必要的情况外，不向无关第三方提供个人数据。

## 玩家选择与权利

- 云账号安全界面提供账号数据导出、设备会话撤销和永久注销。
- 云存档上传、下载和历史恢复需要明确操作；冲突不会静默覆盖。
- 排行榜可以切换为隐私模式并撤回当前公开记录。
- 未登录反馈和错误无法可靠关联到具体个人；需要删除此类记录时，请提供足以定位记录但不包含敏感数据的信息。

隐私请求可以通过游戏内反馈入口或仓库维护者的 GitHub 账号提出。不要在公开 Issue 中提交个人数据。

## 安全与未成年人

项目使用 HTTPS 限制、密码派生、令牌摘要、限流、最小权限、加密备份和访问控制降低风险，但任何网络服务都无法保证绝对安全。

未达到所在地独立同意年龄的用户应在监护人同意和指导下使用服务。监护人认为未成年人数据被不当处理时，可以联系维护者请求核查和删除。

## 政策更新

数据类型、用途或运营主体发生实质变化时，本政策会更新生效日期，并通过仓库或版本公告说明。
